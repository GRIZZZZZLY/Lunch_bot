## 🐛 Известные Проблемы

### 1. **Старые Активные Polls**
**Проблема:** Polls, созданные ДО обновления, могут иметь старое поведение (3 сообщения)

**Решение:** Дождаться завершения старых polls или закрыть их вручную

### 2. **Кэш React Query**
**Проблема:** Старые данные в кэше могут показывать устаревший UI

**Решение:** 
```typescript
// Очистить кэш в DevTools
queryClient.clear()

// Или перезагрузить страницу с Ctrl+Shift+R
```
