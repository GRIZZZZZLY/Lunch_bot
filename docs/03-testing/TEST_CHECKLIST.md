# ✅ Чек-лист тестирования (финальная версия)

## 🚀 Быстрый старт

1. **Перезапустить фронтенд:**
   ```bash
   cd telegram-food-bot/frontend
   Ctrl+C
   npm run dev
   ```

2. **Очистить кэш браузера:**
   - `Ctrl+Shift+R` или `Ctrl+Shift+Delete`
   - Выбрать "Кэшированные файлы"
   - Удалить

3. **Перезапустить в Telegram:**
   - Закрыть WebApp
   - Открыть через `/start`

## 📋 Основные тест-кейсы

### ✅ 1. Навигация (4 кнопки)

**Визуальные проверки:**
- [ ] В нижней навигации РОВНО 4 кнопки (не 5!)
- [ ] Порядок кнопок слева направо:
  - [ ] 🏠 Главная (с badge)
  - [ ] 🍽️ Меню
  - [ ] 📊 Статистика
  - [ ] 👤 Профиль
- [ ] Кнопка "Голосование" 🗳️ ОТСУТСТВУЕТ
- [ ] Badge "1" на кнопке "Главная" (если есть активное голосование)
- [ ] Pulse анимация на badge (мерцание)

**Функциональные проверки:**
- [ ] Все кнопки кликабельны
- [ ] Переходы работают корректно
- [ ] Active состояние работает (текущая страница подсвечена)
- [ ] Haptic feedback при клике

### ✅ 2. Пустое состояние (НЕТ активного голосования)

**Визуальная структура:**
```
┌────────────────────────────┐
│         🕐                  │
│                            │
│ Нет активных голосований   │
│ Ожидайте запуска...        │
│                            │
│ ┌────────────────────────┐ │
│ │ 🗳️ Создать голосование │ │ ← Главная кнопка!
│ └────────────────────────┘ │
│                            │
│ [📜 История голосований]   │
└────────────────────────────┘
```

**Проверки:**
- [ ] Иконка 🕐 (часы) 64px, центрирована
- [ ] Заголовок "Нет активных голосований" (18px, жирный)
- [ ] Описание "Ожидайте запуска от администратора" (14px)
- [ ] Отступ 24px между блоками
- [ ] **Большая кнопка "Создать голосование":**
  - [ ] Высота: 56px (h-14)
  - [ ] Ширина: 100% (w-full)
  - [ ] Цвет: фиолетовый градиент (purple-500 → purple-600)
  - [ ] Иконка 🗳️ размером 22px
  - [ ] Текст "Создать голосование" 16px, жирный
  - [ ] Тень видна (shadow-md)
  - [ ] Скругление 12px (rounded-xl)
- [ ] Отступ 24px
- [ ] Кнопка "История голосований" (36px, outline стиль)

**Функциональность:**
- [ ] **Клик "Создать голосование":**
  - [ ] Haptic feedback срабатывает (средняя вибрация)
  - [ ] Переход на `/poll/create`
  - [ ] Форма создания открывается
- [ ] **Клик "История голосований":**
  - [ ] Переход на `/vote/history`
  - [ ] История показывается корректно
- [ ] **Hover эффект (desktop):**
  - [ ] При наведении: градиент темнеет (purple-600 → purple-700)
  - [ ] Тень увеличивается (shadow-lg)
  - [ ] Плавный переход (200ms)
