# Матрица доступа

Обозначения: **Г** — гость, **П** — аутентифицированный пользователь,
**У** — активный участник нужной группы, **А** — администратор нужной группы,
**С** — создатель группы (в текущей модели те же изменяющие права, что у А),
**ГА** — глобальный администратор поддержки, **О** — отдельный секрет
служебных операций.

Базовое правило: идентификатор из запроса только указывает, что загрузить.
Группа объекта, членство и роль берутся из базы. При сомнении запрос
отклоняется. ГА получает поддержку чтения, но не право действовать от имени
участника или изменять чужую группу.

## API

| Действие | Минимальный доступ | Область и условия | Возврат |
|---|---|---|---|
| `/health/live`, `/health/ready`, `/health` | Г | только состояние процесса/БД/Redis, без секретов | минимальный JSON |
| `POST /api/auth/validate` | Г + свежий Telegram `initData` | подпись, возраст ≤ 5 минут, допустимый небольшой сдвиг часов | access/refresh JWT и собственный профиль |
| `POST /api/auth/refresh` | Г + одноразовый refresh JWT | issuer, audience, алгоритм, срок, `jti`; повтор запрещён Redis | новая пара токенов |
| `GET /api/auth/me`, `/status` | П | только текущий пользователь | собственные минимальные данные |
| `/api/user/me`, `/payment-info` | П | только собственные данные; изменение только своих платёжных реквизитов | собственный профиль/реквизиты |
| `GET /api/user/groups` | П | только активные членства пользователя | его группы |
| `/api/user/:userId/avatar`, `/avatars/batch`, `/avatar/:fileId` | П/У | аватары только доступных пользователей; `fileId` проходит серверный прокси Telegram | изображение или минимальный ответ |
| чтение `/api/menu/*` | У | меню выбранной/выведенной группы; ГА — только поддержка чтения | блюда без скрытых полей |
| изменение `/api/menu/*` | А/С | блюдо и целевые группы проверяются в БД | изменённое блюдо |
| создание/просмотр своих `/api/suggestions` | У | только группа активного участника | предложение |
| статистика, одобрение, отклонение, удаление предложения | А/С | группа предложения, а не переданный `groupId` | состояние предложения |
| чтение `/api/polls/*` | У; собственная статистика П; ГА чтение | объект и активное членство одной группы | голосование/минимальная статистика |
| создание, повтор, завершение, отмена, рулетка `/api/polls/*` | А/С | допустимое состояние; блюда и участники той же группы; `Idempotency-Key` | новое состояние |
| голосование и удаление голоса `/api/polls/*`, `/api/votes/*` | У | пользователь активен, участвует в опросах, голосование открыто, блюдо разрешено | собственный голос/итог |
| `/api/recurring/*` чтение | У | расписание группы | расписание/история |
| `/api/recurring/*` изменение | А/С | группа расписания из БД; идемпотентность | состояние расписания |
| чтение `/api/budget/debts`, `/credits`, `/stats` | П | только долги и поступления текущего пользователя | личные суммы |
| чтение итогов голосования/заказа `/api/budget/*/:pollId` | У | группа голосования | групповые итоги без чужих реквизитов |
| `mark-paid`, `cancel-mark` | владелец долга У | только собственный долг, допустимое состояние, идемпотентность | состояние долга |
| `confirm-payment`, `mark-all-paid`, стоимость заказа | ответственный/А по объекту | долг и голосование одной группы, условный переход | подтверждённые суммы |
| напоминания `/api/budget/*` | ответственный/А | адресаты из той же группы, ограничение частоты, идемпотентность | число отправок |
| чтение заказов по категориям | У | голосование/заказ той же группы; «my» — только свой | заказ/прогресс |
| добавление/удаление позиции | У | только своя позиция, пока заказ редактируем | позиция |
| доброволец категории | допустимый участник У | участвовал в категории, место свободно; атомарный захват | назначение или 409 |
| финализация и стоимость категории | ответственный/А | только рабочее состояние, транзакция, идемпотентность | финальный заказ |
| чтение `/api/store-runs/*` | У | активный участник группы похода | поход и допустимые позиции |
| создание похода | У | только собственная активная группа; идемпотентность | новый поход |
| изменение позиции | владелец позиции У | только `COLLECTING`, принадлежность походу | позиция |
| начало покупок, цены, расчёт, отмена | инициатор/ответственный/А | условный переход текущего состояния; идемпотентность | новое состояние/долги |
| чтение и правка `/api/groups/:groupId/stores` | У | активный участник группы; переименование отклоняется при занятом названии | справочник магазинов группы |
| `/api/user/item-presets` | владелец | только свои записи; чужой идентификатор отвечает 404 | личный список товаров |
| `/api/notifications/*` | У, изменяющее — А/ответственный | группа из БД, ограничение частоты | состояние cooldown/результат |
| `POST /api/donations/stars` | П | фиксированная валюта Stars, допустимая сумма, идемпотентность | ссылка/счёт |
| `POST /api/feedback` | П | длина и тип; журнал без текста и Telegram ID | подтверждение |
| личные `/api/gamification/user/*` | П | только текущий пользователь | личный опыт/достижения |
| `/api/gamification/leaderboard` | У | минимальные публичные поля участников группы | рейтинг |
| `/api/seasons` чтение | П/У; ГА чтение | личная или групповая статистика по доступу | сезон/минимальная статистика |
| `award-xp`, `recalculate-ratings`, `seasons/create`, `seasons/rotate` | ГА + О | функция включена явно, отдельный секрет ≥32, `Idempotency-Key` | результат операции |
| `/api/insights/budget` | П | собственные данные | личная аналитика |
| `/api/insights/budget/:userId` | сам пользователь или ГА чтение | без группового обхода | аналитика пользователя |
| `/api/insights/categories` | У | агрегаты доступной группы | агрегаты |
| `/api/admin` чтение | А/С своей группы; ГА поддержка чтения | обязательный `groupId`/группа объекта | данные одной группы |
| `/api/admin` изменения | А/С своей группы | ГА без членства не проходит; идемпотентность | изменённый объект |
| `/api/metrics*` | ГА | только служебная учётная запись | метрики |
| `/api/polls/:pollId/stream` | У | JWT только в заголовке; группа голосования; предел соединений | SSE одной группы |
| `/api/test/*` | отсутствует в production | физически не подключено | 404 |

Для всех `POST/PUT/PATCH/DELETE`, которые меняют деньги или состояние,
обязателен `Idempotency-Key`; ключ включает метод и путь, поэтому не может
переиспользовать ответ другого маршрута.

## Telegram-команды и callback

| Обработчик | Доступ | Проверка объекта и состояния |
|---|---|---|
| `/start`, `/help`, `/menu`, `/app` | пользователь Telegram | подпись данных далее проверяет API; групповые ссылки создаются из найденного членства |
| `openpoll`, `optin` | активный участник | голосование его группы и открытое состояние |
| `complete_poll`, `cancel_poll`, `run_roulette` | А/С группы голосования | роль повторно читается из БД; чужой чат/глобальная роль не заменяют её |
| `volunteer` | активный ожидаемый участник голосования | место свободно; условное назначение |
| `volunteer_category` | активный участник категории | категория и пользователь из одной группы; условное назначение |
| бюджетные callback | владелец долга либо ответственный/А по операции | долг/поход/группа и текущее состояние из БД |
| `recurring:disable:<id>` | А/С группы расписания | расписание загружается по ID, затем проверяется его группа |
| `pre_checkout_query` | плательщик счёта | payload, сумма и валюта совпадают |
| `successful_payment` | Telegram | уникальные charge ID и атомарная повторная обработка |
| `/webhook` | Telegram + секрет | постоянное по времени сравнение заголовка |

## Отрицательная матрица

Каждая строка выше применяет следующие общие отрицательные случаи:

1. нет JWT/initData → `401`;
2. объект отсутствует или недоступен → `403/404` без его содержимого;
3. пользователь группы A и администратор группы A против объекта B → отказ;
4. неактивное членство → отказ;
5. ГА без членства пытается изменить группу → отказ;
6. ID дочернего объекта другой группы → отказ;
7. неверное состояние → `409/422`;
8. повтор без/с тем же ключом → обязательный ключ либо тот же результат;
9. гонка двух допустимых запросов → ровно один переход/назначение;
10. неверный тип, диапазон или размер → `400/413/422`.

Покрытие закреплено тестами сервисов голосования, бюджета, заказов, походов,
middleware Telegram/JWT/idempotency, контроллера администрирования, платежей,
расписаний и интеграционным тестом параллельного начисления опыта.
