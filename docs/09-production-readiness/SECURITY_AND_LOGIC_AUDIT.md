## Средние — исправлены

- CORS теперь возвращает `403`, выполняется до разбора тела и разрешает
  `Idempotency-Key`; запрещённый origin не получает CORS-заголовок.
- превышение 256 КБ возвращает `413`, битый JSON — `400`, оба ответа имеют
  `traceId` и не содержат стек.
- API имеет request/headers/keep-alive timeouts 30/35/5 секунд.
- test routes физически не подключаются в production.
- health минимален; readiness проверяет PostgreSQL и Redis; метрики закрыты.
- логгер фильтрует токены, initData, Telegram/chat ID, имя, реквизиты, body,
  query, URL и стеки. Необработанное исключение завершает процесс.
- `PollService.updatePoll` принимает белый список полей вместо `Partial<Poll>`.
- CORS в production принимает только явно перечисленные HTTPS origins.
- безопасно сериализуются BigInt через JSON replacer.
- фоновые задания защищены Redis/PG блокировками; снять чужую блокировку нельзя.
- startup polling не удаляет накопленные обновления Telegram.
- процесс завершает HTTP, бота, Redis и Prisma с предельным временем 10 секунд.

## Низкие

- сообщения некоторых старых внутренних модулей смешивают русский и английский;
  наружный контракт уже единообразен.
- `/api/stats` сохранён как совместимый `NOT_IMPLEMENTED`; удалить после
  проверки клиентов.
- в тестах основного интерфейса есть предупреждения устаревшего `act`, не
  влияющие на production.

## Зависимости

- `backend npm audit --omit=dev`: 0.
- основной `frontend-new` переведён на React Router 7.18.1. Применимые проблемы
  внешних переходов исправлены. `npm audit` сообщает о
  `GHSA-qwww-vcr4-c8h2`, затрагивающем только экспериментальные серверные
  компоненты, которых в Vite SPA нет; точечное исключение проверяется
  `npm run audit:prod`.
- инструменты разработки: backend 24 high, основной frontend 19 high; это
  транзитивные `glob/minimatch/brace-expansion` и цепочки Jest/ESLint/Storybook/
  Lighthouse. Они не входят в runtime-образ. CI блокирует high именно для
  `--omit=dev`; полный аудит отслеживается как остаточный риск.

## Секреты и персональные данные

- tracked `.env` нет; отслеживаются только `.env.example`.
- поиск форматов приватного ключа и Telegram-токена по отслеживаемым файлам
  совпадений не дал.
- production-журналы не содержат initData, JWT, тела, query, Telegram ID,
  платёжные реквизиты и стек.
