🚀 Rocket Lunch
Redesign System

Связная визуальная система — от палитры до расположения кнопок. Применимо поэтапно, без рефакторинга логики.

🎨

Ключевое решение — двойной характер: Light = оранжевый (#c9581c) как единственный primary-цвет кнопок, CTA и акцентов. Фиолетовый — только декоративный (иконки, DNA-graph, badges) и никогда для CTА. Dark = фиолетовый (#7c6cf0) как primary для всех кнопок и навигации; оранжевый уходит в accent (вторичные highlights, иконки). Dark-тема переходит с warm-mahogany на cool slate для максимального pop фиолетового.

☀️ Light Mode — Orange Primary

Warm beige + burnt sienna orange (#c9581c) как единственный primary CTA-цвет. Фиолетовый (#7c6cf0) — только декоративный: иконки, DNA-graph, progress bars — но никогда на кнопках. Ощущение: уютное, аппетитное, решительное.

🌙 Dark Mode — Purple Primary

Cool slate base + #7c6cf0 как primary для всех кнопок, nav-активного состояния, FAB. Оранжевый уходит в accent: иконки, вторичные highlights. Cool dark максимально раскрывает глубину фиолетового.

Правило: border или shadow — не оба одновременно на одном элементе.
• В light-теме: card = border-1px (виден на бежевом фоне) + лёгкая тень (rest).
• В dark-теме: card = border вместо тени (тени на тёмном фоне почти не видны). Конкретно: border border-white/[0.06].
