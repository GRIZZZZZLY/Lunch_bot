I3 — Оранжевый текст цены не проходит WCAG AA в light-теме
color · globals.css --primary · MenuPage, DishCard
📱 menu_with-items_light 📱 menu_search_light
Что не так
#D86A2C on #FFF — 3.1:1 ✗
#D86A2C on #FAF7F3 — 2.9:1 ✗
#B85520 on #FFF — 4.7:1 ✓

Цена блюда (₽280, ₽320 и т.д.) рендерится в text-primary = --primary: 23 69% 51% = #D86A2C. На белых и бежевых карточках контраст 3.1:1 — ниже WCAG AA (требуется 4.5:1 для обычного текста). Особенно критично для шрифта 14–16px без bold.

Решение
/* src/styles/globals.css — light theme */
- --primary: 23 69% 51%; /* #D86A2C */
+ --primary: 21 72% 42%; /* #B85520 — контраст 4.7:1 на белом */

/* Все оранжевые CTA-кнопки (bg-primary) затронутся —
   но на белом тексте кнопок контраст только улучшится.
   
   Альтернатива: не трогать --primary, но для текста цены
   использовать отдельный токен --price-ink: */
+ --price-ink: 21 72% 38%; /* тёмный оранж для текста */

/* DishCard.tsx — в компоненте цены */
- <span className="text-primary font-semibold">₽{price}</span>
+ <span className="font-bold tabular-nums" style={{color:'hsl(var(--price-ink))'}} >₽{price}</span>
