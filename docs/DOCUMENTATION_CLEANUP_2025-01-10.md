## 📚 Рекомендации по поддержке

### Когда архивировать документ:

1. **Sessions/Snapshots** - сразу после завершения сессии (через 1-2 недели)
2. **Redesign/Features** - после завершения работы и интеграции в production
3. **Reports** - после завершения фазы/проекта
4. **UX/Planning** - когда появляется новая версия плана/аудита

### Структура для новых документов:

```
/docs/
├── {XX-topic}/           # Нумерованные папки для основных тем
│   ├── README.md         # Индекс папки
│   └── ...
└── archive/
    └── {category}/       # Категория архивных документов
        └── ...
```
