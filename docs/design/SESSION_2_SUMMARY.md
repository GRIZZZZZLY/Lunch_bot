## 🎨 ВИЗУАЛЬНАЯ ТРАНСФОРМАЦИЯ

### MenuPage
**ДО:**
```tsx
<PastelCard variant="sky"> // Голубой фон
```

**ПОСЛЕ:**
```tsx
<PastelCard variant="default" className="border-l-4 border-orange-500">
// Белый фон + оранжевая accent strip
```

**Результат:** Чистота + иерархия цветом полоски

---

### StatsPage
**ДО:**
```tsx
<PastelCard variant="sky">
  <div className="absolute inset-0 bg-gradient-to-br from-lavender-500/20 to-mint-500/20" />
  // Gradient overlay поверх
</PastelCard>
```

**ПОСЛЕ:**
```tsx
<PastelCard variant="default" className="border-l-4 border-orange-500">
  // Чистый белый фон, без градиента
</PastelCard>
```

**Результат:** Убрана визуальная перегруженность, акцент на контент

---

### HomePage
**ДО:**
```tsx
<h1 className="text-xl font-semibold">
```

**ПОСЛЕ:**
```tsx
<h1 className={cn(TYPOGRAPHY_H1.className)}>
// 32px semibold из централизованной шкалы
```

**Результат:** Консистентность типографики во всём приложении
