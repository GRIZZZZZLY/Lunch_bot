# ✅ Исправления InlineVotingCard

## 🐛 Проблемы (решены)

### 1. **Не работает выбор блюд** ❌→✅
**Причина:** Неправильный проп `votes` вместо `voters` в VotersAvatars
```tsx
// Было:
<VotersAvatars votes={poll.votes || []} />

// Стало:
const voters = poll.votes?.map(v => v.user).filter(Boolean) || [];
<VotersAvatars voters={voters} />
```

### 2. **Нет скролла при >2 блюдах** ❌→✅
**Причина:** Карточка выходила за экран при 5+ вариантах
```tsx
// Добавлено:
<div className="max-h-[360px] overflow-y-auto space-y-2 
     scrollbar-thin scrollbar-thumb-white/20 scrollbar-track-transparent pr-1">
```

## 📸 Как протестировать

1. **Обновите страницу** (`Ctrl+R`)
2. Откройте главную страницу
3. Если есть активное голосование:
   - Кликните на любое блюдо
   - Убедитесь, что оно подсвечивается
   - Нажмите "Проголосовать"

   - Убедитесь, что появился scrollbar

   - Выберите блюдо внизу списка
