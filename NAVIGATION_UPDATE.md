### 2. Добавлен контекстный FAB
**Файл:** `frontend/src/pages/HomePage.tsx`

**Концепция:** FAB появляется только когда нужен

**Логика:**
```typescript
// FAB показывается ТОЛЬКО когда:
- НЕТ активного голосования (!activePoll)
- Загрузка завершена (!isLoading)

// FAB скрывается когда:
- ЕСТЬ активное голосование (на главной отображается InlineVotingCard)
- Идёт загрузка
- Пользователь скроллит вниз (hideOnScroll={true})
```

**Особенности:**
- 🎨 **Плавная анимация** появления/исчезновения (scale + opacity)
- 📱 **Haptic feedback** при нажатии
- 🎯 **Скрывается при скролле** (не мешает просмотру)
- 📍 **Позиция:** правый нижний угол (стандарт Telegram Mini Apps)

## 🎨 UX паттерны 2024-2025

Реализация соответствует современным стандартам:

### ✅ Минимализм
- 4 кнопки вместо 5 (меньше = лучше)
- Больше места для каждой кнопки (touch-friendly)

### ✅ Контекстуальность
- FAB появляется только когда актуален
- Не отвлекает когда голосование уже идёт

### ✅ Progressive Disclosure
- Функции раскрываются по мере надобности
- Нет постоянных кнопок "на всякий случай"

### ✅ Соответствие Telegram Mini Apps
- @wallet - 4 кнопки + FAB ✅
- @notcoin - 3 кнопки + центральное действие ✅
- Наше - 4 кнопки + контекстный FAB ✅
