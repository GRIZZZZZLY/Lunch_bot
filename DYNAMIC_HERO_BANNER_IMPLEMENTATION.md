# 🎮 Реализация DynamicHeroBanner с Геймификацией

## ✅ Что сделано

### 1. Созданы новые типы (`frontend/src/types/gamification.types.ts`)
- **UserStats** - статистика пользователя (XP, уровень, рейтинги по 4 категориям)
- **GroupStats** - статистика группы (средние рейтинги, топ участники, серия)
- **QuestReward** - награды за ежедневные действия
- **DailyQuest** - ежедневные задания
- **Achievement** - достижения
- **UserRanking** - позиция в рейтинге
- **LevelProgress** - прогресс уровня
- **RatingCategory** - категории многомерного рейтинга

### 2. Создан Mock сервис (`frontend/src/services/gamification.service.ts`)
Реализует все методы для работы с геймификацией:
- `getUserStats()` - получить статистику пользователя
- `getGroupStats()` - получить статистику группы
- `getTodayRewards()` - получить возможные награды сегодня
- `getDailyQuests()` - получить ежедневные квесты
- `getUserRanking()` - получить рейтинг пользователя
- `calculateLevelProgress()` - рассчитать прогресс уровня
- `getUserAchievements()` - получить достижения

**Важно:** Все данные пока моковые для разработки UI. Когда backend будет готов, нужно заменить на реальные API вызовы.

### 3. Создан компонент DynamicHeroBanner (`frontend/src/components/gamification/DynamicHeroBanner.tsx`)

#### Структура компонента:

```
DynamicHeroBanner (главный компонент)
├── AdminBanner (вариант для администратора)
│   ├── Header (название + кнопки обновить/настройки)
│   ├── Body
│   │   ├── Левая колонка (краткая сводка: участники, серия, средний уровень)
│   │   └── Правая колонка (многомерный рейтинг с топ участниками)
│   │       └── CategoryProgress (прогресс каждой категории)
│   └── Footer (кнопки "Создать" и "Повторить вчерашнее")
│
└── UserBanner (вариант для обычного пользователя)
    ├── Header (аватар + уровень + позиция в рейтинге)
    ├── Progress Section (XP прогресс-бар + серия + до топ-3)
    ├── Rewards List (список возможных наград сегодня)
    │   └── RewardItem (каждая награда с иконкой и XP)
    └── Footer (кнопки "Мои квесты" и "Достижения")
```

#### Ключевые особенности:

**Для Администратора:**
- Показывает статистику всей группы
- Многомерный рейтинг по 4 категориям:
  - 🍽️ Гастрономия (выбор популярных блюд)
  - 🎯 Ответственность (организация заказов)
  - 🤝 Социальность (активность)
  - 🔍 Открытия (новые блюда)
- Топ участник по каждой категории
- Кнопки для создания голосования и повтора вчерашнего

**Для Обычного Пользователя:**
- Показывает личный прогресс
- Текущий уровень с XP прогресс-баром
- Позиция в рейтинге (#5 из 12, ↑2 места)
- Серия дней подряд
- Список возможных наград сегодня:
  - ✅ +20 XP - Первое голосование дня
  - ✨ +30 XP - Голос за новое блюдо
  - 🔥 +15 XP - Продлить серию
- Кнопки для квестов и достижений

## 🔧 Настройка

### Для работы с реальным backend:

1. **Обновить `gamificationService`:**
   Заменить mock данные на реальные API вызовы:
   
   ```typescript
   async getUserStats(userId: number): Promise<UserStats> {
     const response = await apiService.get<UserStats>(`/gamification/users/${userId}/stats`);
     return response.data;
   }
   ```

2. **Добавить эндпоинты на backend:**
   - `GET /api/gamification/users/:userId/stats`
   - `GET /api/gamification/groups/:groupId/stats`
   - `GET /api/gamification/users/:userId/rewards/today`
   - `GET /api/gamification/users/:userId/quests/daily`
   - `GET /api/gamification/users/:userId/ranking`

3. **Подключить WebSocket:**
   Для real-time обновления рейтинга и статистики:
   
   ```typescript
   useEffect(() => {
     const socket = io(API_URL);
     socket.on('stats:updated', (data) => {
       setGroupStats(data);
     });
     return () => socket.disconnect();
   }, []);
   ```
