## ✅ Что было сделано

### 1. Создан компонент `InlineVotingCard`
**Файл:** `frontend/src/components/voting/InlineVotingCard.tsx`

Полноценный компонент голосования со всей логикой:
- ✅ Отображение списка блюд с выбором
- ✅ Реал-тайм обновление голосов
- ✅ Отображение процентов и статистики
- ✅ Таймер обратного отсчёта
- ✅ Индикатор лидера (👑)
- ✅ Автообновление каждые 10 секунд
- ✅ Кнопка завершения для админов

### 2. Переработана `HomePage`
**Файл:** `frontend/src/pages/HomePage.tsx`

**Было:**
```tsx
// Активное голосование → SimplePollCard → кнопка "Голосовать" → переход на /vote/{id}
```

**Стало:**
```tsx
// Активное голосование → InlineVotingCard → голосование БЕЗ перехода
```

**Изменения:**
- ✅ Заменён `SimplePollCard` на `InlineVotingCard`
- ✅ Голосование происходит прямо на главной странице (0 кликов!)
- ✅ Добавлена кнопка "История голосований" в пустое состояние
- ✅ Убран лишний переход на отдельную страницу

### 3. Упрощена маршрутизация в `App.tsx`
**Файл:** `frontend/src/App.tsx`

**Было:**
```tsx
<Route path="/vote" element={<VoteRouter />} />
<Route path="/vote/hub" element={<VotingHubPage />} />
<Route path="/vote/history" element={<PollHistoryPage />} />
<Route path="/vote/:pollId" element={<VotingPage />} />
```

**Стало:**
```tsx
<Route path="/vote" element={<HomePage />} />  // ← Редирект на главную!
<Route path="/vote/history" element={<PollHistoryPage />} />
<Route path="/vote/:pollId" element={<VotingPage />} />  // Для глубоких ссылок
```

**Изменения:**
- ✅ Удалён `VoteRouter` - больше не нужен
- ✅ Удалён `VotingHubPage` - заменён на HomePage
- ✅ `/vote` теперь ведёт на главную страницу
- ✅ Убран избыточный промежуточный слой

## 📊 Результаты

### До рефакторинга:
```
Путь пользователя:
1. HomePage → видит превью
2. Нажимает "Голосовать" → переход на VotingPage

### После рефакторинга:

3. Готово! ✅

Итого: 2 клика + 0 переходов между страницами
```
