# Manual QA — Telegram safe area и viewport

Автотесты (`src/lib/__tests__/viewport.test.ts`, layouts) проверяют логику,
но НЕ заменяют проверку на реальном клиенте Telegram. Прогонять этот чеклист
перед каждым деплоем, затрагивающим shell, BottomSheet или навигацию.

Механизм: `src/lib/viewport.ts` переопределяет `--safe-area-*` и
`--viewport-stable-height` значениями Telegram (safeAreaInset +
contentSafeAreaInset); fallback — `env(safe-area-inset-*)` в
`src/styles/tokens.css`. Страницы обязаны использовать только
`var(--safe-area-*)`.

## Устройства

- [ ] **iOS** (устройство с вырезом/Dynamic Island, iPhone X+)
- [ ] **Android** (устройство с жестовой навигацией и с кнопочной)
- [ ] **Браузер** (Chrome DevTools mobile view — работает env() fallback,
      in-app кнопка «Назад» видна на detail-экранах)

## Сценарии на каждом устройстве

### Root-экран (Главная)
- [ ] Контент не уходит под шапку Telegram (верх приветствия полностью виден)
- [ ] BottomNavigation не перекрыта системной жестовой полосой
- [ ] Последний элемент списка доскролливается выше BottomNavigation
- [ ] FAB не перекрывает BottomNavigation и не обрезан краем экрана

### Detail-экран (например, История голосований)
- [ ] ScreenHeader не наезжает на системную шапку (отступ сверху корректен)
- [ ] Telegram BackButton появляется при входе и исчезает при возврате на root
- [ ] In-app кнопки «Назад» НЕТ (внутри Telegram)
- [ ] Низ контента доскролливается полностью

### BottomSheet
- [ ] Нижний отступ шторки ≥ системной жестовой полосы (кнопки footer нажимаются)
- [ ] Telegram BackButton закрывает шторку, а НЕ уходит с экрана
- [ ] Свайп-вниз Mini App не конфликтует со скроллом шторки

### Открытая клавиатура
- [ ] Поле ввода (поиск в Меню / форма предложения) не перекрыто клавиатурой
- [ ] После закрытия клавиатуры layout возвращается (нет «зависшего» пустого места)
- [ ] BottomSheet с полем ввода: поле видно при открытой клавиатуре
- [ ] `viewportStableHeight`: контент не прыгает при появлении/скрытии клавиатуры

### Темы
- [ ] Светлая/тёмная: цвет шапки и фона Telegram совпадает с канвасом приложения
      (нет цветной полосы на стыке)
- [ ] Смена темы Telegram на лету перекрашивает приложение без перезапуска

## Как фиксировать результат

Дата, устройство/ОС/версия Telegram, галочки, скриншоты проблем — сюда же
в конец файла или отдельным комментарием в PR.
