# Rocket Lunch — спецификация экранов (для дизайна)

Канонические составы экранов с реальными данными. ЭМОДЗИ В ИНТЕРФЕЙСЕ ЗАПРЕЩЕНЫ — иконки только линейные SVG в едином стиле. Тексты кнопок и статусов —
дословные, менять формулировки нельзя. Всё по-русски.

## Навигация

Корневые табы (нижняя навигация всегда видна): **Главная · Меню ·
Статистика · Профиль**. Detail-экраны открываются поверх, нижней навигации
не имеют, «назад» — системная кнопка Telegram: Закупка, Итоги голосования,
История голосований, Предложения блюд, Управление (только админ).

## Главная

- Приветствие: caption «ПЯТНИЦА, 18 ИЮЛЯ», заголовок «Добрый день, Игорь».
- Активное голосование: подпись «Голосуем за обед», статус «Идёт · 12:41»
  (живой таймер), счётчик «13 голосов»; варианты с процент-барами:
  «Том-ям с креветками — 46%» (голос пользователя, выделен),
  «Пицца „Маргарита" — 31%», «Шаурма классическая — 23%».
  Primary-кнопка «Голосовать» (если уже голосовал — «Переголосовать»,
  вторичное действие «Отозвать голос»).
- Секция «Сейчас»: строка активной закупки «Пятёрочка у офиса · Игорь в
  магазине · 2 из 4» + статус «В магазине» (тап → экран закупки);
  строка «Бюджет команды · Вы должны за вчерашний обед · 260 ₽».
- Если голосования нет: пустое состояние «Сегодня ещё не решали» +
  «Запустите голосование — команда выберет обед за пару минут», primary
  «Запустить голосование» (только у тех, кто может создавать).
- После завершения голосования: карточка победителя «Победил Том-ям ·
  6 из 13 голосов · Ответственный: Аня».

## Меню

- Группа: «Офис» (если групп несколько — переключатель).
- Поиск «Поиск блюд»; категории-чипы со счётчиками: «Все · 24», «Супы · 5»,
  «Пицца · 6», «Азиатская · 7», «Десерты · 6».
- Список блюд: название, короткое описание, цена справа:
  «Том-ям с креветками · кокосовое молоко, кинза · 420 ₽»,
  «Пицца „Маргарита" · моцарелла, томаты · 380 ₽»,
  «Тирамису · маскарпоне · 260 ₽».
  Скрытое блюдо показывается приглушённо с пометкой «Скрыто».
- Админ: правка блюда, вкл/выкл, secondary «Добавить блюдо» (форма:
  название, описание, цена, категория). Участник — только просмотр.
- Пустые состояния: «Ничего не нашлось» (поиск), «Меню пока пустое» + CTA
  для админа.

## Статистика

Личное и командное, плоскими секциями (не дашборд из плиток):
- «Вы участвовали в 18 из 22 голосований»;
- серия подряд: «Серия — 5 дней»;
- «Топ блюд команды за месяц»: Том-ям — 7 побед, Пицца — 5, Шаурма — 3
  (список с барами);
- активность по дням недели.
Никаких выдуманных метрик (рейтингов, очков, уровней) — их в продукте нет.

## Профиль

- Шапка: аватар, «Игорь Петров», «@igor».
- Краткие показатели: «Голосований — 18», «Побед блюда — 4»,
  «Серия — 5 дней» (компактной строкой, не дашборд из плиток).
- «Оформление»: переключатель светлая/тёмная тема (реальная функция).
- «Реквизиты для переводов»: «СБП +7 999 123-45-67 · Т-Банк», действие
  «Изменить» (шторка: телефон СБП, банк, номер карты — всё необязательное);
  если не заполнено — показывать «не задано».
- «Мои предложения»: переход к предложениям блюд.
- «Моя история»: последние голосования («Опрос #103 · 17 июля ·
  Завершено»), переход в полную историю.
- Вторичные действия: «Написать отзыв» (шторка), «Поддержать проект»
  (шторка), «Сообщить о проблеме».
- ВАЖНО: «Уведомления» и «Язык» из старого приложения — заглушки, они
  удалены сознательно. Не воспроизводить их в новом дизайне.

## История голосований (detail)

Список: «Опрос #103 · 17 июл. 2026 г. · 13 голосов · Завершено»;
статусы: Активно / Завершено / Отменено. Тап → Итоги.
Пусто: «История пуста · Завершённые голосования появятся здесь.»

## Итоги голосования (detail)

Победитель («Том-ям с креветками · 6 из 13»), распределение голосов по
вариантам, «Ответственный: Аня» (выбирается рулеткой или вызвался сам).

## Предложения блюд (detail)

Участник предлагает блюдо в меню («Предложить блюдо»: название, описание,
цена); статусы предложений: «На рассмотрении» / «Одобрено» / «Отклонено».
Админ одобряет или отклоняет; фильтры «Все / Мои».
