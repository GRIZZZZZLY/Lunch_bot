# Система C — «Нейтрали, цвет = значение» (выбрана владельцем 2026-07-19)

Финальный борд: [shots/system-c-board.png](shots/system-c-board.png) ·
живой: [system-c-board.html](system-c-board.html). Фактура фона —
**перфолента-точки** (выбор владельца).

## Принцип

Каркас — тёплые хроматические нейтрали, **действие не имеет hue**
(чернильная кнопка на светлой, слоновая на тёмной — школа Linear/Vercel).
Цвет существует только там, где несёт значение: домены и статусы.
Эмодзи запрещены; иконки — линейные SVG 1.9px.

## Правила применения

1. Одна чернильная CTA на экран; вторичные — `action-tint`-пилюли или ghost с рамкой.
2. Цвет никогда не декор: каждый цветной элемент отвечает «какого он домена/статуса».
3. Деньги всегда `money` (и суммы, и «Куплено» — одно семейство смысла).
4. Статусы всегда чип «tint-фон + плотный текст того же hue» + слово.
5. Бары: подложка `action-tint`, заполнение — цвет домена (голосование `vote`, сбор `shop`, сегменты закупки `money/danger/нейтраль`).
6. Талон: перфорация dashed `divider` + вырезы цвета canvas; фактура точек — только на canvas, не на surface.
7. Уточнение к борду: полосу таймера СБОРА красить `shop` (на борде зелёная — поправить при переносе).
