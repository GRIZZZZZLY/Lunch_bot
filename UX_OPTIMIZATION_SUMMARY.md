#### 1.4 Telegram Bot - Live-обновляемое Сообщение
**Файлы:** 
- `backend/src/bot/keyboards/poll.keyboard.ts`
- `backend/src/services/poll-reminder.service.ts`

**Изменения:**
- ✅ **Динамический emoji в сообщении:**
  - ⏰ (норма) → ⚠️ (<5 мин) → 🔥 (<2 мин)
- ✅ **Отключены 3 напоминания:**
  - Вместо новых сообщений → редактируется одно

**Результат:**
- **-67% спама** в группах (3 сообщения → 1)
- Чище лента группы
- Пользователи видят live-обновление времени

**Код (keyboard):**
```typescript
// Вычисляем оставшееся время
let timeRemaining = poll.duration || 0;
if (poll.startedAt) {
  const elapsed = Math.floor((Date.now() - new Date(poll.startedAt).getTime()) / 1000 / 60);
  timeRemaining = Math.max(0, (poll.duration || 0) - elapsed);
}

// Определяем emoji на основе времени
let timeEmoji = '⏰';
if (timeRemaining <= 2) {
  timeEmoji = '🔥'; // < 2 мин - HOT!
} else if (timeRemaining <= 5) {
  timeEmoji = '⚠️'; // < 5 мин - срочно
}

message += `${timeEmoji} Осталось: ${timeRemaining} мин\n`;
```

**Код (reminder service):**
```typescript
static scheduleReminders(pollId: number, durationMinutes: number, chatId: bigint): void {
  // UX UPGRADE: ОТКЛЮЧЕНО - вместо 3 сообщений используется 1 live-обновляемое
  logger.info(`[UX] Reminder notifications DISABLED for poll ${pollId} (using live updates instead)`);
  
  // Сохраняем пустую запись для обратной совместимости
  this.reminders.set(pollId, { pollId, timers: {} });
}
```
