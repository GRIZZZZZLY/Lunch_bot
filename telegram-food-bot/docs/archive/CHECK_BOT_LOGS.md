# 📊 Как посмотреть логи и активность бота

## Способ 1: Prisma Studio (рекомендуется)

**Уже запущен:** http://localhost:5555

Откройте в браузере и проверьте таблицы:

### 👤 Users (Пользователи)
Здесь вы увидите всех, кто написал боту `/start`:
- `telegramId` - ID пользователя в Telegram
- `username` - юзернейм
- `firstName` - имя
- `isAdmin` - является ли админом
- `createdAt` - когда зарегистрировался

### 👥 Groups (Группы)  
Группы, в которые добавлен бот:
- `telegramId` - ID группы
- `title` - название группы
- `type` - тип (group, supergroup)
- `isActive` - активна ли

### 🍕 Menu Items (Блюда)
Блюда в меню (пока пусто, добавляются через WebApp)

### 📊 Polls (Голосования)
Созданные голосования

### 🗳️ Votes (Голоса)
Голоса пользователей

## Способ 2: Консоль backend

Backend логирует все действия в консоль. Посмотрите в терминале, где запущен `npm run dev`.

Там будут строки типа:
```
[info]: 📨 Команда получена: /start от @username
[info]: 👤 Пользователь зарегистрирован: 555502880
[info]: 📊 Создано голосование в группе: Test Group
```

## Способ 3: Проверка через SQL запросы

```powershell
# Подключиться к базе через Prisma
cd C:\BOT_V2\telegram-food-bot\backend

# Открыть интерактивную консоль
node
```

Затем в Node.js консоли:
```javascript
const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();

// Посмотреть всех пользователей
prisma.user.findMany().then(console.log);

// Посмотреть все группы
prisma.group.findMany().then(console.log);

// Посмотреть последние действия (users)
prisma.user.findMany({ 
  take: 10, 
  orderBy: { createdAt: 'desc' } 
}).then(console.log);

// Выход
.exit
```

## 📱 Тестирование бота

Отправьте боту команды и проверяйте:

### В личке с ботом:

1. `/start` - должен зарегистрировать вас в базе
2. `/help` - покажет справку
3. `/menu` - попытается открыть WebApp (нужна настройка)

### В группе (после добавления):

1. `/startpoll` - создаст голосование (только для админов)
2. Проверьте ID группы в Prisma Studio

## 🎯 Проверка конкретных взаимодействий

Если вы хотите узнать, что произошло в конкретный момент:

1. Откройте Prisma Studio: http://localhost:5555
2. Перейдите в таблицу **users**
3. Отсортируйте по `createdAt` (по убыванию)
4. Посмотрите последние записи

То же самое для:
- **groups** - когда бот добавлен в группу
- **polls** - когда создано голосование  
- **votes** - когда кто-то проголосовал

## 💡 Полезные SQL запросы (через Prisma Studio)

В Prisma Studio можно выполнить запросы:

### Найти пользователя по ID:
```
telegramId = 555502880
```

### Найти активные голосования:
```
status = "ACTIVE"
```

### Найти голоса конкретного пользователя:
```
userId = 1
```

## 🐛 Если логов нет

Проверьте:
1. Backend запущен? `npm run dev` должен работать
2. В консоли backend должны быть зеленые [info] сообщения
3. Prisma Studio открыт? http://localhost:5555
4. База данных создана? Проверьте файл `backend/prisma/dev.db`
