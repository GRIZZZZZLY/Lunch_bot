## 📖 USAGE GUIDE

### Component Examples

#### Button Primary
```tsx
// Light mode
bg-primary-food-500 text-white hover:bg-primary-food-600

// Dark mode (auto)
dark:bg-primary-food-400 dark:text-slate-900
```

#### Card
```tsx
// Light
<GlassCard variant="medium" theme="light">
  // bg: rgba(255,255,255,0.8)
</GlassCard>

// Dark
<GlassCard variant="medium" theme="dark">
  // bg: rgba(51,65,85,0.7) - slate-700
</GlassCard>
```

#### Badge Success
```tsx
<GlassBadge 
  variant="success"
  theme={isDark ? 'dark' : 'light'}
  // Light: green-500 text
  // Dark: green-300 text (brighter)
/>
```

#### Text Hierarchy
```tsx
<h1 className="text-gray-900 dark:text-slate-50">      // Primary
<p className="text-gray-600 dark:text-slate-200">      // Secondary  
<span className="text-gray-500 dark:text-slate-300">  // Tertiary
<small className="text-gray-400 dark:text-slate-400"> // Muted
```

## 🎨 COLOR PHILOSOPHY

### Light Theme
- **Clean & Fresh:** White backgrounds with subtle grays
- **High Contrast:** Dark text on white for maximum readability
- **Vibrant Accents:** Bold orange for CTAs
- **Minimal Shadows:** Light glassmorphism

### Dark Theme
- **Warm & Comfortable:** Slate (not gray) for warmer feel
- **Reduced Eye Strain:** 15% lighter than typical dark themes
- **Enhanced Visibility:** Brighter accent colors
- **Depth & Dimension:** Enhanced glassmorphism with inner highlights

---

## 🔄 COLOR MAPPING (LIGHT → DARK)

| Light | → | Dark | Reason |
|-------|---|------|--------|
| Gray-900 (`#111827`) | → | Slate-50 (`#F8FAFC`) | Text inversion |
| White (`#FFF`) | → | Slate-800 (`#1E293B`) | BG warmer |
| Gray-50 (`#F9FAFB`) | → | Slate-700 (`#334155`) | Cards lighter |
| Orange-500 (`#F97316`) | → | Orange-400 (`#FB923C`) | Brighter primary |
| Green-500 | → | Green-300 | More visible |
| Red-500 | → | Red-300 | Less harsh |
| Blue-500 | → | Blue-300 | Better contrast |

---

## 🎯 KEY TAKEAWAYS

1. **Slate > Gray:** Warmer, more inviting in dark mode
2. **+20% Brighter Text:** Better readability in dark
3. **+15% Lighter Backgrounds:** Less eye strain
4. **All WCAG AA+:** Accessibility compliant
5. **Glassmorphism Optimized:** Inner highlights add depth
6. **Consistent Orange:** Food theme throughout
