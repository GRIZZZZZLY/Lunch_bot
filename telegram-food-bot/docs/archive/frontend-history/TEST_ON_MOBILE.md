## ✅ РЕШЕНИЕ 1: Тестирование В БРАУЗЕРЕ телефона

Это **самый простой способ** проверить что приложение работает:

### Шаг 1: Откройте браузер на телефоне

**Chrome/Safari на телефоне:**
```
http://192.168.0.113:5173/
```

### Шаг 2: Проверьте что появился alert

Должно появиться:
```
DEBUG:
isReady: true
initData: false (0 chars)
tgUser: false
MOCK: true
```

### Шаг 3: Нажмите OK

Приложение должно открыться БЕЗ ошибки!

**Если это работает**, значит:
- ✅ Приложение работает
- ✅ MOCK режим работает
- ❌ Проблема в Telegram WebApp интеграции

## ✅ РЕШЕНИЕ 2: Настройка для Telegram

Если в браузере работает, но в Telegram нет - нужно настроить бота:

### Вариант A: Используйте ngrok (рекомендуется)

**Почему:** IP адреса (192.168.0.113) не работают в Telegram WebApp

1. **Установите ngrok:**
   - Скачайте: https://ngrok.com/download
   - Распакуйте
   - Зарегистрируйтесь и получите authtoken

2. **Запустите ngrok:**
```bash
ngrok http 5173
```

3. **Скопируйте URL:**
```
Forwarding: https://abc123.ngrok-free.app -> http://localhost:5173
```

4. **Обновите .env:**
```env
VITE_API_URL=https://abc123.ngrok-free.app/api
```

5. **Перезапустите frontend:**
```bash
npm run dev
```

6. **Настройте бота в @BotFather:**
```
/mybots
→ Выберите @rocket_lunch_bot
→ Bot Settings
→ Menu Button
→ Введите URL: https://abc123.ngrok-free.app
```

7. **Откройте бота на телефоне**
   - Найдите @rocket_lunch_bot
   - Нажмите Menu button
   - Должно открыться ваше приложение!

---

### Вариант B: Используйте локальный IP (только для той же WiFi)

**Ограничение:** Телефон должен быть в той же WiFi сети

1. **Проверьте что телефон в той же WiFi что и ПК**

2. **Настройте бота:**
```
@BotFather
→ /mybots
→ @rocket_lunch_bot
→ Menu Button
→ http://192.168.0.113:5173
```

3. **Откройте бота на телефоне**

⚠️ **Может не работать** - Telegram часто блокирует локальные IP

## ✅ РЕШЕНИЕ 3: Используйте MOCK режим БЕЗ backend

Если у вас нет доступа к backend или хотите быстро протестировать:

### Уже сделано:
```env
VITE_USE_MOCK_API=true
```

И в коде:
```typescript
const useMockApi = true; // Захардкожено
```

**Это значит:**
- ✅ Работает БЕЗ backend
- ✅ Все данные mock
- ✅ Авторизация автоматическая

**Если все еще ошибка** - это значит что:
1. Изменения не применились (нужно hard reload)
2. Telegram кэширует старую версию
3. URL бота указывает на старый сервер

## 🐛 ОТЛАДКА

### Проблема: Alert не появляется в Telegram

**Причина:** Telegram WebApp может блокировать alerts

**Решение:** Используем Telegram нативный alert:

```typescript
window.Telegram?.WebApp?.showAlert?.('DEBUG INFO');
```

Это уже добавлено в код!

---

### Проблема: Бот не открывает WebApp

**Возможные причины:**

1. **URL не настроен в BotFather**
   - Решение: Настройте Menu Button в @BotFather

2. **URL недоступен**
   - Локальный IP (192.168.x.x) может не работать
   - Решение: Используйте ngrok

3. **Backend не запущен**
   - Но у вас MOCK режим включен, так что это не должно быть проблемой
