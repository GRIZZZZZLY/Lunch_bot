## ℹ️ Зачем архив?

1. **Историческая справка** - сохранение контекста принятых решений
2. **Снижение шума** - актуальная документация не захламляется старыми файлами
3. **Быстрый доступ** - можно найти старые материалы при необходимости
4. **Версионность** - понимание эволюции проекта
