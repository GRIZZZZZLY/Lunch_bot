## 1. Подготовка окружения

### 1.1 Проверка требований

```powershell
# Проверить Node.js (должен быть 18+)
node --version

# Проверить npm
npm --version

# Проверить PostgreSQL
docker --version
# или
psql --version
```

### 1.2 Установка зависимостей

```powershell
# Перейти в backend
cd C:\BOT_V2\telegram-food-bot\backend

# Установить зависимости
npm install

# Перейти во frontend
cd ..\frontend
npm install
```

### 1.3 Настройка базы данных

**Вариант A: Через Docker (рекомендуется)**

```powershell
cd C:\BOT_V2\telegram-food-bot

# Запустить PostgreSQL
docker-compose up -d postgres

# Проверить, что контейнер запущен
docker ps

# Применить миграции
cd backend
npx prisma migrate dev --name init
npx prisma generate
```

**Вариант B: Локальный PostgreSQL**

```powershell
# Создать базу данных
createdb -U postgres foodbot_db

# Создать пользователя
psql -U postgres -c "CREATE USER foodbot WITH PASSWORD 'foodbot_password';"
psql -U postgres -c "GRANT ALL PRIVILEGES ON DATABASE foodbot_db TO foodbot;"

# Применить миграции
cd C:\BOT_V2\telegram-food-bot\backend
npx prisma migrate dev --name init
```

## 2. Настройка Telegram бота

### 2.1 Создание бота через @BotFather

1. **Открыть Telegram** и найти бота [@BotFather](https://t.me/BotFather)

2. **Создать нового бота:**
   ```
   /newbot
   ```

3. **Ввести имя бота:**
   ```
   Food Order Bot
   ```

4. **Ввести username бота** (должен заканчиваться на `_bot`):
   ```
   my_food_order_bot
   ```

5. **Скопировать токен:**
   ```
   7592503226:AAE7XJZd6TPW_aWzcHg2QiD-X0kHVQ0Br9I
   ```

### 2.2 Настройка бота

**Установить описание:**
```
/setdescription
@my_food_order_bot
Бот для организации заказов еды в группе. Создавайте голосования и выбирайте, что заказать!
```

**Установить команды:**
```
/setcommands
@my_food_order_bot

start - Начать работу с ботом
help - Показать справку
menu - Показать меню блюд
startpoll - Начать голосование (только для админов)
stats - Показать статистику
```

**Включить режим группы:**
```
/setjoingroups
@my_food_order_bot
Enable
```

**Выключить режим приватности (чтобы бот видел сообщения в группе):**
```
/setprivacy
@my_food_order_bot
Disable
```

### 2.3 Настройка .env файлов

**Backend (.env):**
```env

BOT_USERNAME=my_food_order_bot
BOT_WEBHOOK_URL=  # Оставить пустым для polling режима

# Telegram WebApp Configuration
TELEGRAM_SECRET_KEY=41522d6eee2d636203d4c629076ab4b7c9fa39547a51a72742bb69cb4d330bc4

# API Configuration
API_PORT=3001
API_HOST=0.0.0.0

# Environment

# Admin Configuration (ваш Telegram ID)
```

**Frontend (.env):**
```env

VITE_BOT_USERNAME=my_food_order_bot
```

## 4. Тестирование через ngrok/webhooks

### 4.1 Установка ngrok

**Скачать:** https://ngrok.com/download

**Или через Chocolatey:**
```powershell
choco install ngrok
```

### 4.2 Запуск ngrok

```powershell
# Запустить туннель для backend
ngrok http 3001

# Скопировать URL (например: https://abc123.ngrok.io)
```

### 4.3 Настройка webhook

**Обновить .env:**
```env
BOT_WEBHOOK_URL=https://abc123.ngrok.io/webhook
```

**Установить webhook вручную:**
```powershell
# Через curl (если установлен)
curl -X POST "https://api.telegram.org/bot7592503226:AAE7XJZd6TPW_aWzcHg2QiD-X0kHVQ0Br9I/setWebhook?url=https://abc123.ngrok.io/webhook"

# Или через браузер
# Открыть: https://api.telegram.org/bot<YOUR_TOKEN>/setWebhook?url=https://abc123.ngrok.io/webhook
```

**Проверить webhook:**
```
https://api.telegram.org/bot<YOUR_TOKEN>/getWebhookInfo
```

### 4.4 Запуск Mini App через ngrok

```powershell
# В отдельном терминале
```

## 7. Решение проблем

### Проблема: Бот не отвечает

**Диагностика:**
```powershell
# Проверить, что backend запущен
# Должен быть запущен процесс node

# Проверить логи
cd C:\BOT_V2\telegram-food-bot\backend
# Посмотреть на ошибки в консоли

# Проверить токен бота
curl "https://api.telegram.org/bot<YOUR_TOKEN>/getMe"
```

**Решение:**
- Проверить правильность токена в .env
- Проверить подключение к интернету
- Убедиться, что бот не заблокирован Telegram

### Проблема: База данных не подключается

**Диагностика:**
```powershell
# Проверить, что PostgreSQL запущен
docker ps | findstr postgres

# Проверить подключение
docker exec -it telegram-food-bot-postgres psql -U foodbot -d foodbot_db -c "SELECT 1;"
```

**Решение:**
```powershell
# Перезапустить контейнер
docker-compose restart postgres

# Или пересоздать
docker-compose down
docker-compose up -d postgres
```

### Проблема: Mini App не загружается

**Диагностика:**
1. Открыть DevTools в браузере (F12)
2. Проверить Console на ошибки
3. Проверить Network для запросов к API

**Решение:**
- Проверить, что frontend запущен
- Проверить CORS настройки в backend
- Проверить URL в переменных окружения
- Проверить, что открыто через Telegram (не напрямую)

### Проблема: Голосование не создается

**Диагностика:**
```powershell
# Проверить активные блюда в БД
docker exec -it telegram-food-bot-postgres psql -U foodbot -d foodbot_db -c "SELECT * FROM menu_items WHERE is_active = true;"
```

**Решение:**
- Убедиться, что есть минимум 2 активных блюда
- Проверить права бота в группе
- Проверить, что пользователь - админ группы

### Проблема: Рулетка не запускается

**Диагностика:**
- Проверить, что есть проголосовавшие пользователи
- Проверить логи на ошибки

**Решение:**
- Убедиться, что AUTO_ROULETTE_ENABLED=true
- Проверить, что голосование завершено корректно
