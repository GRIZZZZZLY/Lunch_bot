# 🚀 Быстрая отладка - Памятка

## 📱 Получить логи с iPhone (3 простых шага)

### 1️⃣ Откройте Debug Logger
- Нажмите кнопку **🐛** в правом верхнем углу
- Или сделайте **тройной тап** в любом месте экрана

### 2️⃣ Воспроизведите ошибку
- Очистите логи кнопкой **"Clear"**
- Выполните действие которое вызывает ошибку
- Дождитесь завершения

### 3️⃣ Сделайте скриншот
- Скриншот всей панели Debug Logger
- Отправьте мне

---

## 🖥️ Получить логи Backend (1 команда)

## 🔍 Что искать в Debug Logger

### ✅ Все ОК - видите такие логи:
```
🔍 Checking active poll for group 1...
✅ No active poll - can create new one
📤 [PollsService] Creating poll from WebApp
🌐 [API] POST /polls/create-from-webapp
✅ [API] POST success
```

### ❌ Ошибка - видите:
```
❌ [API] POST /polls/create-from-webapp failed
{
  "error": "...",
  "code": "...",
  "status": 400
}
```

**Отправьте скриншот всего блока с ❌**

## 💡 Полезные команды

### Просмотр логов backend:
```powershell
# Последние 100 строк
.\show-logs.ps1

# Последние 200 строк
.\show-logs.ps1 -Type tail -Lines 200

# Только ошибки
.\show-logs.ps1 -Type error

# Мониторинг в реальном времени
Get-Content backend\logs\combined-*.log -Tail 50 -Wait
```
