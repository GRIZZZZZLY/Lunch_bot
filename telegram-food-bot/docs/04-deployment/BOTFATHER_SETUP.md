# Настройка Rocket Lunch в BotFather

## Базовые параметры

В [@BotFather](https://t.me/BotFather):

1. откройте `/mybots` и выберите бота;
2. разрешите добавление в группы;
3. настройте Menu Button для личных чатов;
4. укажите HTTPS-адрес Mini App;
5. задайте команды.

Актуальные команды сервера:

```text
start - Начать работу
help - Показать справку
menu - Открыть меню
app - Открыть Rocket Lunch
```

Не добавляйте в BotFather команды, которых нет в
`backend/src/bot/bot.ts`.

## Адрес Mini App

Для продакшена:

```text
https://rocketlunch.dpdns.org
```

Для локальной проверки используйте временный HTTPS-адрес, который выводит
`start-prod-dev.ps1`. Не сохраняйте временный адрес в документации.

Тот же адрес должен находиться в `WEBAPP_URL`, а его источник — в
`CORS_ORIGIN`.

## Личные и групповые чаты

Кнопка типа `web_app` работает в личном чате. В группе сервер не отправляет
такую кнопку напрямую: пользователь получает обычную глубокую ссылку или
инструкцию перейти в личный чат с ботом.

Это поведение реализовано в:

- `backend/src/bot/keyboards/webapp.keyboard.ts`;
- `backend/src/bot/commands/start.ts`;
- `backend/src/bot/commands/menu.ts`;
- `backend/src/bot/commands/app.ts`.

## Privacy Mode

Отключайте Group Privacy только если боту действительно нужно получать обычные
сообщения группы. Для команд с `/` это не всегда требуется. Избыточный доступ
увеличивает объём данных, которые видит бот.

## Права в группе

Выдавайте только необходимые права. Удаление сообщений нужно для очистки
служебных сообщений голосований и закупок; остальные административные права
не включайте без необходимости.

## Проверка

1. В личном чате выполните `/start` и откройте Menu Button.
2. В группе выполните `/start` и `/app`.
3. Убедитесь, что глубокая ссылка сохраняет контекст группы.
4. Проверьте создание голосования и закупки.
5. Просмотрите серверные журналы на ошибки Telegram API.

## Безопасность

- не публикуйте токен бота;
- при утечке немедленно отзовите токен через BotFather;
- не используйте боевого бота в автоматических тестах;
- не записывайте Telegram `initData` в журналы.

Официальная документация:
[Telegram Mini Apps](https://core.telegram.org/bots/webapps).
