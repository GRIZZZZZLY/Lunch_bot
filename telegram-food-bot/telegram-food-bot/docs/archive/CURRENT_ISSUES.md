## 🔧 ДЕТАЛИ ОШИБОК

### Несоответствие Prisma схемы и кода

**Схема (актуальная):**
```prisma
model Poll {
  id         Int        @id @default(autoincrement())
  createdAt  DateTime   @default(now())
  updatedAt  DateTime   @updatedAt
  createdBy  Int
  groupId    Int
  status     PollStatus @default(ACTIVE)  // НЕ isActive!
  duration   Int
  startedAt  DateTime   @default(now())
  endedAt    DateTime?                     // НЕ endTime!
  // messageId НЕ СУЩЕСТВУЕТ
  ...
}
```

**Код (устаревший):**
```typescript
// poll.service.ts
const poll = await prisma.poll.findFirst({
  where: { isActive: true }  // ❌ Ошибка! Нет такого поля
});

poll.endTime // ❌ Ошибка! Нет такого поля
poll.messageId // ❌ Ошибка! Нет такого поля
```

**Нужно:**
```typescript
const poll = await prisma.poll.findFirst({
  where: { status: 'ACTIVE' }  // ✅ Правильно
});

poll.endedAt // ✅ Правильно
// messageId хранить в отдельной таблице или вообще убрать
```
