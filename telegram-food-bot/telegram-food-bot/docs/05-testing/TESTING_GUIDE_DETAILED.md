## 🔧 Подготовка окружения

### 1. Проверка конфигурации Backend

**Файл:** `telegram-food-bot/backend/.env`

Убедитесь, что у вас настроены все переменные окружения:

```bash
# Database
DATABASE_URL="postgresql://username:password@localhost:5432/lunch_bot"

# Telegram Bot
TELEGRAM_BOT_TOKEN="ваш_токен_бота"
TELEGRAM_WEBHOOK_DOMAIN="https://ваш-домен.ngrok-free.app"

# Frontend URL
FRONTEND_URL="https://ваш-домен.ngrok-free.app"

# Server
PORT=3000
NODE_ENV=production
```

### 2. Проверка базы данных

```powershell
# В директории backend
cd E:\BOT_V2\Lunch_bot\telegram-food-bot\backend

# Проверка миграций Prisma
npx prisma migrate status

# Если нужно - применить миграции
npx prisma migrate deploy

# Или создать базу с нуля
npx prisma migrate reset
```

## 📱 Настройка Telegram Bot

### 1. Обновить .env файл Backend

Откройте `telegram-food-bot/backend/.env` и обновите:

```bash
TELEGRAM_WEBHOOK_DOMAIN="https://abcd1234.ngrok-free.app"
FRONTEND_URL="https://efgh5678.ngrok-free.app"
```

### 2. Перезапустить Backend

```powershell
# Остановите backend (Ctrl+C) и запустите снова
cd E:\BOT_V2\Lunch_bot\telegram-food-bot\backend
npm start
```

### 3. Настроить Mini App в BotFather

1. Откройте Telegram, найдите @BotFather
2. Отправьте команду `/mybots`
3. Выберите ваш бот
4. Нажмите **"Bot Settings" → "Menu Button" → "Configure Menu Button"**
5. Отправьте название: `🍽 Открыть меню`
6. Отправьте Web App URL:
   ```
   https://efgh5678.ngrok-free.app
   ```

### 4. Настроить команды бота

Отправьте @BotFather команду `/setcommands`, выберите бота и отправьте:

```
start - Начать работу с ботом
menu - Открыть меню
app - Открыть веб приложение
poll - Создать голосование
groups - Управление группами
help - Помощь
```

## 🧪 Тестирование функционала

### Сценарий 1: Первый запуск и регистрация

1. **Откройте бота в Telegram**
   ```
   https://t.me/ваш_бот_username
   ```

2. **Нажмите кнопку "START"**
   - Должно появиться приветственное сообщение
   - Пользователь автоматически регистрируется в базе

3. **Нажмите кнопку меню "🍽 Открыть меню"**
   - Должен открыться Mini App с вашим фронтендом
   - Появится приветственное модальное окно (WelcomeModal)

---

### Сценарий 2: Управление блюдами

#### A. Создание блюда (через Admin)

1. **Откройте Mini App**
2. **Перейдите на страницу /menu**
3. **Нажмите "+" (кнопка добавления)**
4. **Заполните форму:**
   - Название: "Пицца Маргарита"
   - Описание: "Классическая пицца с моцареллой"
   - Цена: 450
   - Категория: "Пицца"
   - URL изображения: `https://example.com/pizza.jpg`
   - Активное блюдо: ✅ Включено

5. **Нажмите "Добавить блюдо"**
   - Блюдо должно появиться в списке

#### B. Редактирование блюда

1. **Нажмите на карточку блюда**
2. **Нажмите "Изменить"**
3. **Измените данные**
4. **Нажмите "Сохранить изменения"**

#### C. Удаление блюда

1. **Нажмите на карточку блюда**
2. **Нажмите "Удалить"**
3. **Подтвердите в модальном окне**
   - Должно появиться красивое модальное окно с белым фоном
   - Кнопки "Удалить" (красная) и "Отмена" (серая)

---

### Сценарий 3: Создание и запуск голосования

#### A. Создание группы (если нет)

1. **В Telegram создайте группу**
2. **Добавьте бота в группу**
3. **Сделайте бота администратором**
4. **В Mini App → /poll/create**
5. **Выберите группу из списка**

#### B. Создание голосования

1. **Откройте Mini App → /poll/create**
2. **Выберите группу**
3. **Введите название:** "Обед на сегодня"
4. **Выберите длительность:** 30 минут
5. **Выберите блюда для голосования** (минимум 2)
   - Отметьте галочками нужные блюда
   - Например: ✅ Пицца, ✅ Бургер, ✅ Салат

6. **Нажмите "Создать голосование"**
   - В группе должно появиться сообщение с голосованием
   - С inline кнопками для каждого блюда

---

### Сценарий 4: Голосование

1. **В группе Telegram нажмите на любую кнопку блюда**
   - Кнопка должна подсветиться
   - Появится эмодзи ✅ рядом с названием
   - Счётчик голосов увеличится

2. **Нажмите на другую кнопку**
   - Предыдущий выбор сбросится
   - Новая кнопка подсветится
   - Счётчик обновится

3. **Откройте Mini App → /voting**
   - Должна отображаться активная poll
   - Таймер обратного отсчёта
   - Ваш выбор должен быть отмечен

---

### Сценарий 5: Статистика

1. **После завершения голосования**
2. **Откройте Mini App → /stats**
3. **Должна отображаться статистика:**
   - Популярные блюда с иконкой Trophy 🏆
   - Количество голосов
   - История голосований
   - Графики (если есть данные)

4. **Проверьте сортировку:**
   - По дате
   - По количеству голосов
   - По названию

---

### Сценарий 6: Профиль пользователя

1. **Откройте Mini App → /profile**
2. **Заполните данные:**
   - Номер карты (для оплаты)
   - Номер телефона
   - Дополнительная информация

3. **Нажмите "Сохранить изменения"**
   - Данные должны сохраниться
   - При повторном открытии - данные загружаются

## 🐛 Возможные проблемы и решения

### Проблема 1: ngrok "Visit Site" страница

**Симптом:** При открытии ngrok URL показывается страница "Visit Site"

**Решение:**
```bash
# Добавьте в заголовки ответа (если нужно)
ngrok http 3000 --host-header=rewrite
```

### Проблема 2: CORS ошибки

**Решение:** Проверьте в backend `.env`:
```bash
FRONTEND_URL="https://ваш-ngrok-url.ngrok-free.app"
```

И перезапустите backend.

### Проблема 3: Telegram init data недоступен

**Симптом:** "No Telegram init data available"

**Решение:** Убедитесь, что:
1. Mini App открывается ТОЛЬКО из Telegram
2. URL в BotFather настроен правильно
3. Backend webhook настроен правильно

### Проблема 4: База данных не подключается

**Решение:**
```powershell
# Проверить PostgreSQL
pg_ctl status

# Создать базу данных
createdb lunch_bot

# Применить миграции
cd backend
npx prisma migrate deploy
```

## 📝 Примечания

1. **После изменения кода frontend** - пересобирайте build:
   ```powershell
   npm run build
   ```
   И перезапустите preview сервер.

2. **После изменения backend** - перезапустите сервер:
   ```powershell
   npm start
   ```

3. **ngrok URL меняется** при каждом перезапуске - обновляйте:
   - Backend `.env`
   - BotFather Web App URL
   - Перезапускайте backend

4. **Для production деплоя** используйте:
   - Frontend: Vercel/Netlify/Cloudflare Pages
   - Backend: Railway/Render/Heroku
   - Database: Supabase/Neon/Railway
