mini-app · home widget

One widget, seven states, resolved by priority.

BudgetWidgetWithCalculator is the single component that occupies the post-poll slot on HomePage. The backend exposes {role, txState} and the widget walks the priority ladder below to pick the highest-applicable scenario. It never renders two at once.

meta

State machine notes

for dev handoff
transition triggers
P1a → P1b   calc submitted
P1b → P1c   all debts confirmed
P2a → P2b   roulette resolved
P2b → P1*   (if admin also becomes responsible)
P3a → P3b   user marks paid
P3b → P3a   user cancels mark
P3b → P3c   responsible confirms
P3c → ∅      after 5s · pill receipt persists
priority gotchas
· P1 always wins over P3 even if responsible also owes someone from yesterday — yesterday's debt moves to history tab
· P2 and P3 are mutually exclusive by role
· HiddenState is the only gate that renders nothing
· widget is keyed by poll_id; new poll = fresh resolution
