# Rocket Lunch — оверлеи: шторки, подтверждения, рулетка

Все формы и подтверждения — нижние шторки (bottom sheet): скругление сверху,
ручка-полоска, заголовок + крестик, кнопки внизу «Отмена | <действие>».
Системная кнопка «назад» Telegram закрывает верхнюю шторку, а не уходит с
экрана. Пока идёт сохранение — обе кнопки заблокированы, на действии спиннер.

## Создание голосования (шторка, только у тех, кто может создавать)

- Выбор группы (если групп несколько).
- Выбор блюд из меню группы: список с чекбоксами, поиск; счётчик «Выбрано 5».
- Длительность: пресеты «15 · 30 · 60 минут».
- Режим: «Разовое» / «По расписанию». По расписанию: дни недели
  (Пн…Пт чипами) и время («11:30») — голосование будет запускаться
  автоматически. Подпись: «Запускается автоматически в выбранные дни».
- Кнопка «Запустить голосование» (для расписания — «Сохранить расписание»).

## Закупка

- «Добавить позицию» / «Изменить позицию» (шторка): «Что купить»
  (обязательное, до 200), «Количество» (1–99, по умолчанию 1), «Заметка»
  (необязательно, до 500). Ошибка не закрывает шторку и не теряет ввод.
- Подтверждения (диалог-шторка с двумя кнопками):
  «Удалить позицию?» — название удаляемого, «Удалить» разрушительная;
  «Закрыть сбор досрочно?» — «Участники больше не смогут добавлять позиции»;
  «Отменить закупку?» — разрушительная;
  «N позиций не обработано» — «Они не попадут в расчёт. Продолжить?»,
  кнопка «Рассчитать без них».

## Меню (админ)

- «Добавить блюдо» / «Изменить блюдо» (шторка): название, описание, цена,
  категория. Удаление блюда — через подтверждение.

## Профиль

- «Реквизиты для переводов» (шторка): телефон СБП, банк, номер карты —
  все поля необязательные.
- «Написать отзыв» (шторка): текст + отправить.
- «Поддержать проект» (шторка): суммы-пресеты + произвольная.

## Рулетка выбора ответственного (полноэкранный оверлей)

Показывается после завершения голосования, когда ответственного выбирает
случайность (если никто не вызвался сам):
- затемнённый фон; по центру крупная «барабанная» лента имён проголосовавших,
  которая прокручивается с замедлением и останавливается на выбранном;
- финал: крупно имя («Ответственный — Аня»), блюдо-победитель рядом,
  кнопка «Понятно»;
- настроение лёгкое и быстрое (1.5–2.5 с), без конфетти-спама; уважать
  reduced motion (мгновенный результат без прокрутки).
Тексты: заголовок «Кто идёт за обедом?», финал «Ответственный — {Имя}».

## Приветственная шторка новичка (первый вход)

Короткое «Как это работает»: 3 пункта (голосуем → победитель → ответственный
забирает и делит счёт), кнопка «Понятно». Показывается один раз.
