# Rocket Lunch — экран «Закупка» (Store Run), полная спецификация

Групповая закупка в магазине. Машина состояний (статус задаёт сервер):
**СБОР → В МАГАЗИНЕ → РАССЧИТАНО**, из СБОРА возможна ветка **ОТМЕНЕНО**
(из «В магазине» отмена только автоматическая по таймауту).
Заголовок экрана всегда — название магазина + статус словом.

Роли: **инициатор** (создал закупку) и **участник**. Права жёсткие:
редактировать/удалять позицию может ТОЛЬКО её владелец (инициатор чужие
не трогает); цены и статусы позиций отмечает ТОЛЬКО инициатор и только
в состоянии «В магазине».

## СБОР (COLLECTING)

Общее: сводка (аватар, «Инициатор: Игорь», «2 участника · 3 позиции»);
живой таймер до закрытия сбора: «13:59 · до 14:30» + полоса прогресса.
Позиции сгруппированы по участникам, секция «Мои позиции» первой:
- «Хлеб бородинский» (моя — иконки правки и удаления, 44×44);
- «Кофе Lavazza Qualità Oro ×2 · тёмная обжарка, если есть» (моя);
- секция «Аня · 1»: «Молоко 3.2% ×2 · синюю пачку» (чужая — без иконок).

Участник: внизу primary «Добавить позицию» (форма: «Что купить»
обязательное, «Количество» 1–99, «Заметка» необязательная).
Инициатор: primary «Закрыть сбор» (недоступна при 0 позиций), вторичная
разрушительная «Отменить закупку», а «Добавить позицию» — вторичная кнопка
в секции своих позиций. Удаление, отмена и досрочное закрытие — через
диалог подтверждения.
Таймер истёк, но сервер ещё не перевёл статус: плашка «Сбор закрывается…»,
добавление ещё доступно.
Пусто: «Пока пусто · Добавьте первую позицию — остальные подтянутся.»

## В МАГАЗИНЕ (SHOPPING)

Инициатор (режим «одной рукой», крупные тап-зоны):
- прогресс: «Обработано 2 из 4» + «осталось 2» + полоса;
- секции СТРОГО в порядке: «Осталось» → «Куплено» → «Не нашли»;
- строка: название ×кол-во, заметка, владелец мелко справа;
- «Осталось»: кнопки «Куплено» и «Не нашли». Тап «Куплено» раскрывает
  ВСТРОЕННЫЙ ввод цены прямо в строке (не отдельное окно): поле
  «Цена за всё, ₽» (при ×N — «Цена за всё (×2), ₽»; цена за всю строку,
  не за штуку; 0 допустим), кнопки «Отмена» / «Сохранить»;
- «Куплено»: статус «Куплено» + цена «112,5 ₽», действия «Изменить цену»,
  «Не нашли»;
- «Не нашли»: статус «Не нашли», действие «Всё-таки куплено»;
- внизу primary «Рассчитать». Если есть необработанные — диалог
  «2 позиции не обработано · Они не попадут в расчёт. Продолжить? ·
  Рассчитать без них». Пока открыт ввод цены — «Рассчитать» недоступна;
- инфо-плашка: «Завершите расчёт после покупки. Незавершённая закупка
  может быть отменена автоматически.»

Участник (только просмотр): «Игорь в магазине», общий прогресс, «Ваши
позиции» со статусами и ценами, «Ваша текущая сумма: 180 ₽», остальные
позиции списком, плашка «Инициатор рассчитает закупку после магазина.»

## РАССЧИТАНО (SETTLED) — только просмотр

Инициатору: «Вам должны: 725 ₽» главным числом, ниже «Ваши покупки: 320 ₽»
и «Итого закупки: 1 045 ₽». Участнику: «Ваша часть: 260 ₽» (если 0 —
нейтральное «С вас ничего не требуется», без большого нуля) + «Итого».
Плашка: «Расчёты созданы. Участники увидят суммы в Telegram.»
Разбивка по участникам: у каждого — сумма и его позиции со статусами
(«Куплено 612,5 ₽» / «Не нашли» / «Не обработано · Не вошло в расчёт»);
группа инициатора помечена «Инициатор», его сумма — «свои покупки», не долг.
В конце вторичная кнопка «На главную». Никаких кнопок-действий.

## ОТМЕНЕНО (CANCELLED) — только просмотр

Причина: «Закупка отменена инициатором.» либо «Закупка отменена
автоматически: расчёт не был завершён вовремя.» История позиций по
участникам (статус «Запрошено» у необработанных). Пусто: «В закупке не
было позиций». В конце — «На главную».
