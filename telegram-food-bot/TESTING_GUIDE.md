## 🎯 Сценарий тестирования (30 минут)

### Шаг 1: Проверка меню через Prisma Studio (5 мин)

```powershell
cd C:\BOT_V2\telegram-food-bot\backend
npx prisma studio
```

Откроется http://localhost:5555

**Что проверить:**
1. Откройте таблицу `MenuItem`
2. Убедитесь, что там 15 блюд
3. Все блюда `isActive = true`
4. Проверьте цены и категории

---

### Шаг 2: Создание тестовой группы в Telegram (3 мин)

1. Откройте Telegram
2. Создайте новую группу: **"Food Bot Test"**
3. Добавьте @rocket_lunch_bot в группу
4. Сделайте бота **администратором** группы
   - Группа → Настройки → Администраторы → Добавить администратора → @rocket_lunch_bot

**Важно:** Бот должен быть админом, чтобы создавать голосования!

---

### Шаг 3: Тест базовых команд (5 мин)

#### В личке с ботом:

1. Отправьте: `/start`
   - Ожидаемый ответ: Приветствие
   - Проверка в Prisma Studio: в таблице `users` появился ваш пользователь

2. Отправьте: `/help`
   - Ожидаемый ответ: Список доступных команд

#### В группе:

3. Отправьте: `/start`
   - Ожидаемый ответ: приветствие для группы

4. Проверьте в Prisma Studio:
   - Таблица `groups` → появилась ваша группа

---

### Шаг 4: Запуск голосования (5 мин)

**В тестовой группе:**

1. Отправьте команду: `/startpoll`
   или с таймером: `/startpoll 5` (голосование на 5 минут)

**Ожидаемое поведение:**
- ✅ Появится сообщение с голосованием
- ✅ Будут кнопки со всеми 15 блюдами
- ✅ Кнопки управления внизу:
  - 🔄 Обновить
  - 📊 Результаты

**Что проверить в Prisma Studio:**
- Таблица `polls` → создано новое голосование
- Статус: `ACTIVE`
- Время окончания установлено

---

### Шаг 5: Голосование (10 мин)

#### Тест с одним пользователем:

1. Нажмите на любое блюдо (например, 🍕 Маргарита)
   - Должно появиться уведомление: "✅ Вы проголосовали за Маргарита"
   - Счетчик голосов обновится: "🍕 Маргарита (1)"

2. Попробуйте изменить голос (нажмите другое блюдо)
   - Уведомление: "🔄 Голос изменен на [новое блюдо]"
   - Счетчик обновится

3. Нажмите "🔄 Обновить"
   - Сообщение обновится с актуальными данными

4. Нажмите "📊 Результаты"
   - Покажет промежуточные результаты

**Проверка в Prisma Studio:**
- Таблица `votes` → ваш голос записан
- Связан с pollId и userId

#### Тест с несколькими пользователями:

Если есть возможность:
5. Попросите друга/коллегу проголосовать
6. Или используйте другой аккаунт Telegram

**Ожидаемое:**
- Счетчики голосов обновляются для всех
- Каждый пользователь видит текущее состояние

---

### Шаг 6: Завершение голосования (5 мин)

#### Вариант A: Ручное завершение

1. Нажмите кнопку "✅ Завершить голосование"

**Что должно произойти:**
- ✅ Голосование закрывается
- ✅ Показываются финальные результаты
- ✅ Блюдо-победитель определено (больше всего голосов)
- ✅ Кнопки голосования исчезают
- ✅ Появляется кнопка "🎲 Запустить рулетку"

#### Вариант B: Автоматическое завершение

Если указали таймер (например, `/startpoll 1`):
- Подождите 1 минуту
- Голосование автоматически завершится

**Проверка в Prisma Studio:**
- Таблица `polls` → статус изменился на `COMPLETED`
- Таблица `pollResults` → создан результат с победителем

---

### Шаг 7: Рулетка (5 мин)

1. Нажмите кнопку "🎲 Запустить рулетку"

**Ожидаемое поведение:**
- ✅ Появится сообщение "🎰 Запуск рулетки..."
- ✅ Текст будет меняться (анимация выбора)
- ✅ Финальное сообщение:
  ```
  🎉 Рулетка завершена!
  
  🎯 Ответственный за заказ: [Имя пользователя]
  🍽️ Заказываем: [Блюдо-победитель]
  
  📞 Ожидаем заказа! 🚀
  ```

**Проверка в Prisma Studio:**
- Таблица `pollResults` → поле `responsibleUserId` заполнено
- Это ID случайного пользователя из проголосовавших

## 🐛 Возможные проблемы и решения

### Проблема: Бот не отвечает на команды

**Решение:**
1. Проверьте, что backend запущен:
   ```powershell
   cd C:\BOT_V2\telegram-food-bot\backend
   npm run dev
   ```
2. Проверьте логи в консоли backend

---

### Проблема: "/startpoll" говорит "Меню пусто"

**Решение:**
1. Проверьте в Prisma Studio таблицу `menuItems`
2. Если пусто, запустите seed еще раз:
   ```powershell
   npx tsx prisma/seed.ts
   ```

---

### Проблема: Нет кнопок в голосовании

**Решение:**
1. Проверьте в Prisma Studio что `isActive = true` для блюд
2. Перезапустите backend
3. Попробуйте `/startpoll` снова

---

### Проблема: Рулетка не запускается

**Решение:**
1. Убедитесь, что голосование завершено (статус COMPLETED)
2. Проверьте, что есть хотя бы один голос
3. Проверьте логи backend на ошибки

---

### Проблема: Кнопки не реагируют

**Решение:**
1. Проверьте callback handlers в логах backend
2. Убедитесь, что бот запущен в polling режиме
3. Перезапустите backend
