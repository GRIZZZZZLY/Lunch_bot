# 🗳️ Режим голосования: Single Choice vs Multi Winner

## 🎯 Текущая ситуация

### Ваше голосование работает в режиме **Single Choice** (один голос на пользователя)

**Как это работает:**

```
Пользователь 1: Голосует за "Пицца" → ✅ Засчитано
                Меняет голос на "Паста" → ✅ Обновлено (НЕ добавлено новое!)
                
Пользователь 2: Голосует за "Суши" → ✅ Засчитано
                Меняет голос на "Бургер" → ✅ Обновлено (НЕ добавлено новое!)
```

### Что вы видите в проблеме:

> "Второй пользователь выбирает другой вариант, его голос не засчитывается, и общее количество голосов не увеличивается"

**Это ПРАВИЛЬНОЕ поведение для Single Choice!**

---

## 🔍 Диагностика проблемы

### Вариант 1: Второй пользователь МЕНЯЕТ свой голос

Если второй пользователь **уже голосовал** и выбирает другой вариант:

✅ **Ожидаемое поведение:**
- Старый голос удаляется
- Новый голос сохраняется
- **Общее количество голосов НЕ увеличивается** (остается 1 голос от этого пользователя)
- Счетчик на старом блюде уменьшается (-1)
- Счетчик на новом блюде увеличивается (+1)

❌ **Проблема:**
Если вы видите, что "последний выбранный вариант отображается", но счетчик не меняется - это БАГ в обновлении UI!

---

### Вариант 2: Второй пользователь голосует ВПЕРВЫЕ

Если второй пользователь **ещё НЕ голосовал** и выбирает вариант впервые:

✅ **Ожидаемое поведение:**
- Создается новый голос
- **Общее количество голосов УВЕЛИЧИВАЕТСЯ** (теперь 2 голоса)
- Счетчик на выбранном блюде увеличивается (+1)

❌ **Проблема:**
Если счетчик не увеличивается - это БАГ в backend или в обновлении UI!

---

## 🔧 Режимы голосования

### 1️⃣ **Single Choice** (текущий режим) ⭐

**Что это:**
- Каждый пользователь может выбрать **только одно блюдо**
- Может **изменить свой выбор** в любой момент
- При изменении старый голос заменяется новым

**Prisma schema:**
```prisma
model Vote {
  @@unique([pollId, userId]) // ← Один голос на пользователя
}
```

**Пример:**
```
Голосование за обед:
  - Пицца: 5 голосов (Пользователи: Иван, Мария, Петр, Анна, Сергей)
  - Суши: 3 голоса (Пользователи: Ольга, Денис, Елена)
  - Паста: 2 голоса (Пользователи: Алексей, Виктор)

Итого: 10 пользователей = 10 голосов
```

✅ **Когда использовать:**
- Заказ еды на группу (один победитель)
- Выбор места встречи
- Любое решение с одним вариантом

---

### 2️⃣ **Multi Winner** (завершение с несколькими победителями)

**Что это:**
- Голосование остается **Single Choice**
- Но при завершении определяются **несколько победителей**
- Например: топ-3 блюда с наибольшим количеством голосов

**Backend код:**
```typescript
await pollsService.completePollMultiWinner(poll.id, {
  minVotes: 1,      // Минимум голосов для победы
  maxWinners: null, // Неограниченно победителей
  tieBreakMethod: 'earliest', // Метод разрешения ничьей
});
```

**Пример:**
```
Голосование за обед (Multi Winner):
  🥇 Пицца: 5 голосов → Победитель 1
  🥈 Суши: 3 голоса → Победитель 2
  🥉 Паста: 2 голоса → Победитель 3

Результат: Заказываем все 3 блюда!
```

✅ **Когда использовать:**
- Заказ для большой компании (закажем топ-3)
- Выбор нескольких активностей
- Распределение задач

---

### 3️⃣ **Multiple Choice** (НЕ реализовано) ❌

**Что это:**
- Каждый пользователь может выбрать **несколько блюд**
- Например: "Что вы хотите на обед?" - можно выбрать Пицца + Суши + Паста

**Prisma schema (нужно изменить):**
```prisma
model Vote {
  // Убрать unique constraint!
  // @@unique([pollId, userId]) ← УДАЛИТЬ
}
```

**Пример:**
```
Голосование "Что хотите попробовать?" (Multiple Choice):
  - Пицца: 8 голосов (Иван✓, Мария✓, Петр✓, Анна✓, Сергей✓, Ольга✓, Денис✓, Алексей✓)
  - Суши: 5 голосов (Мария✓, Петр✓, Ольга✓, Елена✓, Алексей✓)
  - Паста: 3 голоса (Иван✓, Анна✓, Виктор✓)

Итого: 10 пользователей = 16 голосов (пользователи голосовали за несколько блюд)
```

❌ **Статус:** НЕ реализовано в вашем проекте!

## ✅ Решение проблемы

### Если второй пользователь МЕНЯЕТ голос (уже голосовал):

**Это правильное поведение!**

- ✅ Общее количество голосов НЕ увеличивается (1 пользователь = 1 голос)
- ✅ Счетчик на старом блюде уменьшается (-1)
- ✅ Счетчик на новом блюде увеличивается (+1)
- ✅ В зеленом блоке "Вы проголосовали за: ..." показывается новый выбор

**Нет проблемы! Система работает корректно.**

---

### Если второй пользователь голосует ВПЕРВЫЕ:

**Общее количество голосов ДОЛЖНО увеличиться!**

Если этого не происходит - это БАГ:

#### Возможная причина 1: Проблема с автообновлением UI

**Решение:**
1. Сделайте Pull to Refresh (потяните страницу вниз)
2. Проверьте логи backend (должно быть `Vote created`)
3. Проверьте базу данных через Prisma Studio

#### Возможная причина 2: Кэширование данных

**Решение:**

Добавьте принудительное обновление после голосования:

```typescript
// frontend/src/pages/VotingPage.tsx
// Строка ~230
const handleVote = async () => {
  // ... существующий код ...
  
  // После успешного голосования:
  await new Promise(resolve => setTimeout(resolve, 500)); // Подождать 500ms
  await loadPollData(false); // Полное обновление с loader
  setRefreshKey(prev => prev + 1); // Принудительный rerender
};
```

#### Возможная причина 3: Проблема с подсчетом в backend

**Проверка:**

```powershell
cd backend
npx prisma studio
```

1. Откройте таблицу `votes`
2. Отфильтруйте по `pollId`
3. Посчитайте количество записей вручную

**Если в БД голоса есть, но не отображаются:**
- Проблема в API endpoint `/api/polls/:id`
- Проверьте логи backend

## 🚀 Если хотите Multiple Choice

### Изменения в backend:

#### 1. Prisma Schema

```prisma
model Vote {
  id           Int      @id @default(autoincrement())
  pollId       Int      @map("poll_id")
  userId       Int      @map("user_id")
  menuItemId   Int?     @map("menu_item_id")
  // ...
  
  // ❌ УДАЛИТЬ unique constraint
  // @@unique([pollId, userId])
  
  // ✅ ДОБАВИТЬ unique constraint для предотвращения дублей
  @@unique([pollId, userId, menuItemId])
}
```

#### 2. Vote Service

```typescript
// backend/src/services/vote.service.ts

static async toggleVote(data: CreateVoteData): Promise<Vote> {
  const existing = await prisma.vote.findFirst({
    where: {
      pollId: data.pollId,
      userId: data.userId,
      menuItemId: data.menuItemId,
    },
  });

  if (existing) {
    // Убираем голос (toggle off)
    await prisma.vote.delete({ where: { id: existing.id } });
    return existing;
  } else {
    // Добавляем голос (toggle on)
    return await prisma.vote.create({
      data: {
        pollId: data.pollId,
        userId: data.userId,
        menuItemId: data.menuItemId,
        voteType: VoteType.MENU_ITEM,
      },
    });
  }
}
```

#### 3. Frontend VotingPage

```tsx
// frontend/src/pages/VotingPage.tsx

const [selectedItemIds, setSelectedItemIds] = useState<number[]>([]);

const handleSelectItem = (itemId: number) => {
  if (selectedItemIds.includes(itemId)) {
    // Убрать из выбранных
    setSelectedItemIds(prev => prev.filter(id => id !== itemId));
  } else {
    // Добавить к выбранным
    setSelectedItemIds(prev => [...prev, itemId]);
  }
};

const handleVote = async () => {
  for (const itemId of selectedItemIds) {
    await pollsService.voteForItem(pollId, itemId);
  }
};
```
