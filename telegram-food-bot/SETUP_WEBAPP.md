# Настройка Telegram WebApp для бота

## Текущая ситуация
Бот запущен: @rocket_lunch_bot  
Backend работает: http://localhost:3001  
Frontend нужно настроить для WebApp

## Шаг 1: Запустить frontend

```powershell
cd C:\BOT_V2\telegram-food-bot\frontend
npm install  # Если еще не установлены зависимости
npm run dev
```

Frontend будет доступен на: http://localhost:5173

## Шаг 2: Установить ngrok (для публичного доступа)

### Вариант A: Через Chocolatey
```powershell
choco install ngrok
```

### Вариант B: Скачать вручную
1. Скачать с https://ngrok.com/download
2. Распаковать ngrok.exe в удобную папку
3. Добавить в PATH или запускать из папки

## Шаг 3: Запустить ngrok для frontend

```powershell
ngrok http 5173
```

Вы получите URL типа: `https://abc123.ngrok.io`

## Шаг 4: Настроить WebApp в BotFather

1. Открыть @BotFather в Telegram
2. Отправить команду: `/mybots`
3. Выбрать вашего бота: **Food Order Bot**
4. Нажать: **Bot Settings** → **Menu Button**
5. Выбрать: **Configure menu button**
6. Отправить:
   - **Button text**: Меню 🍕
   - **URL**: https://abc123.ngrok.io (ваш ngrok URL)

## Шаг 5: Настроить команды бота

В @BotFather:

```
/setcommands
```

Выберите вашего бота и отправьте:

```
start - Начать работу с ботом
help - Показать справку
menu - Открыть меню блюд
startpoll - Начать голосование (только админы)
stats - Показать статистику
```

## Шаг 6: Настроить описание бота

```
/setdescription
```

Выберите бота и отправьте:

```
🍕 Бот для организации заказов еды в группе

Возможности:
• Создание голосований за блюда
• Случайный выбор ответственного за заказ
• Управление меню через WebApp
• Статистика заказов

Добавьте меня в группу и используйте /startpoll для начала голосования!
```

## Шаг 7: Настроить краткое описание

```
/setabouttext
```

```
Организуйте заказы еды в группе легко и весело! 🍕🎰
```

## Альтернатива: Без ngrok (для локального тестирования)

Если ngrok недоступен, можно протестировать без WebApp:

1. Бот будет работать только с командами
2. Управление меню можно сделать через команды бота (позже)
3. WebApp можно настроить позже при деплое

## Текущие команды бота

Какие команды уже работают:
- `/start` - регистрация пользователя
- `/help` - справка
- Другие команды могут требовать доработки

## Проверка логов бота

Чтобы увидеть, что происходило в чате, можно:

1. **Посмотреть консоль backend** - там выводятся все логи
2. **Проверить базу данных**:
   ```powershell
   cd C:\BOT_V2\telegram-food-bot\backend
   npx prisma studio
   ```
   Откроется веб-интерфейс для просмотра данных
