## 🚀 Запуск Backend

### Вариант 1: Через скрипт (РЕКОМЕНДУЕТСЯ)

```powershell
# Из корня проекта telegram-food-bot
.\dev-start-backend.ps1
```

Скрипт автоматически:
- Проверит/создаст .env файл
- Установит зависимости (если нужно)
- Применит миграции
- Запустит сервер в dev режиме

### Вариант 2: Вручную

```powershell
cd backend

# Копировать dev конфигурацию (если еще не сделано)
Copy-Item .env.development -Destination .env

# Установить зависимости
npm install

# Применить миграции
npx prisma migrate deploy

# Запустить
npm run dev
```

### ✅ Backend запущен, если видите:

```
✅ Приложение успешно запущено
Bot is running in polling mode...
API Server is running on http://127.0.0.1:3001
```

### 2. Тестирование голосований (в группе)

> **ВАЖНО:** Для полноценного тестирования нужна группа Telegram

#### 2.1 Создание тестовой группы

```
Шаг 1: Создайте новую группу в Telegram
Шаг 2: Добавьте бота @rocket_lunch_bot в группу
Шаг 3: Сделайте бота администратором (опционально)
```

#### 2.2 Быстрое голосование (/quick)

```
Шаг 1: В группе отправьте: /quick
Шаг 2: Выберите продолжительность:
   • 30 минут (стандарт)
   • Другое время

Ожидается:
✅ Сообщение с кнопками всех блюд
✅ Таймер обратного отсчета
✅ Возможность проголосовать за блюдо
```

#### 2.3 Голосование

```
Шаг 1: Нажмите на любое блюдо (например, 🍕 Маргарита)

Ожидается:
✅ Уведомление "Ваш голос учтен!"
✅ Обновленный счетчик голосов
✅ Подсветка выбранного блюда
```

#### 2.4 Переголосование

```
Шаг 1: Нажмите на другое блюдо (например, 🍝 Карбонара)

Ожидается:
✅ Старый голос отменен
✅ Новый голос учтен
✅ Счетчики обновились
```

### 3. Тестирование рулетки

#### 3.1 Ожидание завершения голосования


## 🐛 Частые проблемы

### Backend не запускается

```
Проблема: Error: Cannot find module...
Решение: cd backend && npm install
```

```
Проблема: Database connection error
Решение: 
  cd backend
  npx prisma migrate deploy
  npx prisma generate
```

```
Проблема: Bot token invalid
Решение: Проверьте BOT_TOKEN в backend/.env
```

### Бот не отвечает

```
Проблема: Бот молчит в Telegram
Решение:
  1. Проверьте, что backend запущен
  2. Проверьте логи в консоли
  3. Убедитесь что NODE_ENV=development
  4. Проверьте что webhook отключен (пустой BOT_WEBHOOK_URL)
```

### Голосование не создается

```
Проблема: Ошибка при создании голосования
Решение:
  1. Убедитесь что бот добавлен в группу
  2. Проверьте что в меню есть блюда (npm run seed)
  3. Проверьте логи backend
```

### Frontend не подключается к backend

```
Проблема: API errors in console
Решение:
  1. Проверьте что backend запущен (localhost:3001)
  2. Проверьте VITE_API_URL в frontend/.env.development
  3. Убедитесь что VITE_USE_MOCK_API=false
```
