# 🚀 Quick Start - Тестирование нового функционала

## 1️⃣ Запустить проект (1 минута)

```powershell
cd E:\Lunch_bot\telegram-food-bot
.\start-prod-dev.ps1
```

Дождитесь запуска всех 5 окон.

---

## 2️⃣ Протестировать FAB (30 секунд)

1. Откройте http://localhost:8080
2. Посмотрите справа внизу → должна быть пульсирующая кнопка 💬
3. Кликните на неё → откроется модалка "Обратная связь"
4. Введите: "Тест"
5. Нажмите "Отправить"
6. Проверьте Telegram → должно прийти сообщение

---

## 3️⃣ Протестировать Welcome Card (30 секунд)

**Открыть консоль браузера (F12):**

```javascript
// Симулировать нового пользователя
localStorage.setItem('user_555502880_poll_count', '0');
location.reload();
```

Должна появиться карточка 🎉 "Добро пожаловать!"

```javascript
// Симулировать опытного пользователя
localStorage.setItem('user_555502880_poll_count', '5');
location.reload();
```

Карточка должна исчезнуть.

---

## ✅ Всё работает?

Если:

- ✅ Сообщение пришло в Telegram
- ✅ Welcome Card показывается/скрывается
