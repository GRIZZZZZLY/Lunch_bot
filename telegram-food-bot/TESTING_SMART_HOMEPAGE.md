## 🐛 Troubleshooting

### Проблема: FAB не видна

**Возможные причины:**
- z-index конфликт
- Bottom Navigation перекрывает

**Решение:**
```tsx
// В FloatingActionButton.tsx
className="... z-40"  // Должно быть выше контента

// Позиция
bottom-20  // 80px снизу (над Bottom Nav)
right-4    // 16px справа
```

---

### Проблема: Сообщение не приходит в Telegram

**Проверьте:**

1. **ADMIN_USER_IDS в .env:**
   ```bash
   # backend/.env
   ADMIN_USER_IDS=555502880  # ← Ваш Telegram ID
   ```

2. **Bot Token актуален:**
   ```bash
   BOT_TOKEN=8298516078:AAF3QAaoVURt634PcNtwMKiExF2nILnziGk
   ```

3. **FeedbackService инициализирован:**
   ```typescript
   // backend/src/index.ts
   feedbackService.initialize(bot);  // ← Должна быть эта строка
   ```

4. **Логи backend:**
   ```bash
   # Должны быть:
   ✅ Feedback service initialized
   📨 Feedback sent to admin
   
   # Не должно быть:
   ❌ Error sending feedback to admin
   ⚠️ ADMIN_USER_IDS not set in .env
   ```

---

### Проблема: Welcome Card не скрывается

**Причина:** Счётчик голосований не обновляется

**Решение:**
```javascript
// Вручную установить счётчик в консоли:
localStorage.setItem('user_555502880_poll_count', '5');
location.reload();
```

**Автоматическое обновление:**
После участия в голосовании нужно обновить счётчик:
```typescript
// После успешного голосования
const currentCount = parseInt(localStorage.getItem(`user_${userId}_poll_count`) || '0');
localStorage.setItem(`user_${userId}_poll_count`, String(currentCount + 1));
```
