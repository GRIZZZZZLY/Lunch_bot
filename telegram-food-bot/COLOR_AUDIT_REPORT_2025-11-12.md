## 🚨 КРИТИЧЕСКИЕ ПРОБЛЕМЫ

### Проблема #1: Success Green на белом фоне

**Текущее:**
```
Цвет: #22C55E (яркий зелёный)
Фон: #FFFFFF (белый)
Контраст: 2.8:1 ❌
WCAG AA требует: 4.5:1
```

**Почему это плохо:**
- ❌ Пользователи с дальтонизмом **не видят** текст
- ❌ На солнце/при ярком свете **нечитаемо**
- ❌ Нарушает WCAG AA (могут быть юридические проблемы)

**Эмоциональное воздействие:**
- 😤 Раздражение ("Почему я не вижу, что написано?")
- 😕 Сомнение ("Это вообще важная информация или нет?")

**Где используется:**
- ✓ Success индикаторы после голосования
- ✓ Подтверждение оплаты
- ✓ Статус "Оплачено"
- ✓ Badges в бюджет-виджете

**Рекомендация:**
```css
/* ИСПРАВИТЬ */
--secondary: 142 76% 37%; /* #16A34A - Green-600 (контраст 4.6:1) */

/* Или использовать темный текст на зелёном фоне вместо зелёного текста на белом */
```

```
Фон: #E5E5E5(серый)
Контраст: 3.2:1 ❌
WCAG AA требует: 4.5:1
```

**Почему это плохо:**
- ❌ Ошибки **не привлекают внимание** (главная функция красного!)

- ❌ Контраст недостаточен для людей с нарушением зрения

**Эмоциональное воздействие:**
- 😰 Тревога, но неявная ("Что-то не так, но что?")
- 🤷 Недоумение ("Это ошибка или просто акцент?")

**Где используется:**
- ❌ Сообщения об ошибках
- ❌ Валидация форм
- ❌ Критические предупреждения

**Рекомендация:**
```css
/* ИСПРАВИТЬ */
--destructive: 0 84% 50%; /* #DC2626 - Red-600 (контраст 5.1:1) */
```

- 🎯 Highlighted карточки

```css
/* ИСПРАВИТЬ */
```

### 2. PRIMARY CTA КНОПКИ

**Темная тема:**
```
Фон кнопки: #FF9D66 (яркий оранжевый)
Текст: #17212b (тёмный)
Контраст: 7.97:1 ✅
```

**Эмоция:** ✅ **Призыв к действию - мягкий, но убедительный**
- Цвет **пробуждает аппетит** (food psychology)
- Яркость привлекает взгляд, но **не режет глаза**
- Тёмный текст на ярком фоне - **необычно**, выделяется
- Пользователь: "Это точно главная кнопка, хочу нажать"

**Оценка:** ⭐⭐⭐⭐ 9/10

**Светлая тема:**
```
Фон кнопки: #C84A00 (тёмный оранжевый)
Текст: #FFFFFF (белый)
Контраст: 4.73:1 ✅
```

**Эмоция:** ⚠️ **Призыв к действию - слишком серьёзный**
- Тёмно-оранжевый выглядит **"обгоревшим"** на светлом фоне
- Менее **appetizing** чем светло-оранжевый
- Ассоциация: "Важная, но не самая приятная кнопка"

**Проблема:** Визуально кнопка выглядит "тяжелой" и менее привлекательной.

**Рекомендация:**
```css
/* Использовать более яркий оранжевый для светлой темы */
--primary: 25 95% 50%; /* #F57C1F - Ярче, аппетитнее */
/* И убедиться что белый текст читается: контраст >4.5:1 */
```

**Оценка:** ⭐⭐⭐ 7/10

## 🚩 ЦВЕТОВЫЕ КОНФЛИКТЫ

### Конфликт #1: Зелёный цвет - 4 разных варианта

**Найдено в коде:**
```typescript
// Mint-500, Mint-400, Green-500, Emerald-400
text-mint-500      // В одном месте
text-green-500     // В другом месте
text-emerald-400   // В третьем месте
bg-green-600       // В четвёртом месте
```

**Проблема:**
- 😵 **Путаница:** "Какой зелёный что означает?"
- 😤 **Непоследовательность:** Success выглядит по-разному в разных местах
- 😰 **Когнитивная нагрузка:** Пользователь учит 4 оттенка вместо 1

**Эмоциональное воздействие:**
- "Это один и тот же статус или разные?"
- "Почему одна галочка яркая, а другая тусклая?"
- Ощущение **недоработанности** дизайна

**Рекомендация:**
```
❌ УДАЛИТЬ: green-*, emerald-*, success-*
✅ ИСПОЛЬЗОВАТЬ ТОЛЬКО: mint-500 (light) / mint-400 (dark)

ONE green = ONE meaning (success)
```

**В коде:**

**Проблема:**
- 🤷 **Semantic конфликт:** Primary = "действие" или "важная информация"?

**Рекомендация:**
