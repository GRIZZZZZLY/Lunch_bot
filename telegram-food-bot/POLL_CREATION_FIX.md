# ✅ Исправление ошибки создания голосования

## 🐛 Проблема

При попытке создать новое голосование возникала ошибка:

```json
{
  "success": false,
  "error": "Group already has an active poll",
  "code": "POLL_ALREADY_ACTIVE",
  "status": 400
}
```

**Причина:** В группе уже было активное голосование, но frontend не проверял это перед попыткой создания.

---

## 🔧 Решение

### 1. Улучшена обработка ошибок
- Добавлена проверка `error.code === 'POLL_ALREADY_ACTIVE'`
- Показывается понятное сообщение: "⏰ В этой группе уже есть активное голосование"
- Улучшено логирование с emoji-индикаторами

### 2. Автоматическая проверка активного голосования
- При загрузке страницы автоматически проверяется активное голосование
- При смене группы также выполняется проверка
- Результат кэшируется в состоянии `existingPoll`

### 3. Предупреждение в UI
Если есть активное голосование, показывается **желтый блок**:
```
⏰ Активное голосование
В выбранной группе уже идет голосование. 
Дождитесь его завершения или завершите вручную через страницу голосования.

[Перейти к голосованию →]
```

### 4. Блокировка создания
- Функция `canCreatePoll()` теперь проверяет `!existingPoll`
- Telegram Main Button скрывается если есть активное голосование
- Невозможно случайно создать дубликат

### 5. Улучшенное логирование

**Frontend:**
```javascript
🔍 Checking active poll for group 1...
⚠️ Active poll found: {...}
// или
✅ No active poll - can create new one
```

**Backend:**
```
✅ Checked existing poll {"exists":true}
❌ Group already has active poll
```
