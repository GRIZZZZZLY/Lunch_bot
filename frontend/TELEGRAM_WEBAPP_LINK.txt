НАСТРОЙКА БОТА (если нужно)
==============================================

Чтобы бот открывал ваше приложение:

1. Откройте @BotFather в Telegram
2. Отправьте: /mybots
3. Выберите вашего бота: @rocket_lunch_bot
4. Нажмите: Bot Settings → Menu Button
5. Укажите URL: http://192.168.0.113:5173/
   (или ваш ngrok URL)

==============================================
ДЛЯ PRODUCTION (потом)
==============================================

Используйте ngrok для постоянного URL:

1. Установите ngrok: https://ngrok.com/
2. Запустите:
   ngrok http 5173

3. Получите URL типа:
   https://abc123.ngrok-free.app

4. Обновите в BotFather:
   Menu Button URL → https://abc123.ngrok-free.app

5. Обновите .env:
   VITE_API_URL=https://abc123.ngrok-free.app/api
