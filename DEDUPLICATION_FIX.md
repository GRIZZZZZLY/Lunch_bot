# 🎯 Устранение дублирования кнопок

## ❌ Проблема

На главной странице было **ДВЕ** одинаковые кнопки "Создать голосование":

### Структура ДО изменений:
```
┌─────────────────────────────────────┐
│         🕐                           │
│ Нет активных голосований            │
│ [🗳️ Создать голосование] ← 1        │ Большая
│ [📜 История голосований]            │
├─────────────────────────────────────┤
│ ⚡ Быстрые действия                  │
│ ┌─────────────────────────────────┐ │
│ │ 🗳️ Голосования                   │ │
│ │ [Создать голосование] ← 2        │ │ Hero Action
│ └─────────────────────────────────┘ │
│ ┌──────┬──────┬──────┐             │
│ │ [👤] │ [⭐] │ [👥] │             │
│ └──────┴──────┴──────┘             │
└─────────────────────────────────────┘
```

**Проблемы:**
- ❌ Дублирование: две одинаковые кнопки рядом
- ❌ Запутывает пользователя
- ❌ Нелогичная структура
- ❌ Перегруженный интерфейс

---

## ✅ Решение

**Убрать Hero Action когда нет активного голосования.**

### Логика:
- **Есть голосование** → Hero Action показывает "Проголосовать"
- **Нет голосования** → Hero Action скрыт, кнопка создания в пустом состоянии

---

## 🔧 Изменения

### Изменение 1: Обновлён тип ScenarioConfig

**Файл:** `frontend/src/pages/HomePage.tsx` (~строка 99)

**Было:**
```typescript
interface ScenarioConfig {
  hero: HeroAction;
  // ...
}
```

**Стало:**
```typescript
interface ScenarioConfig {
  hero: HeroAction | null;  // ← Hero Action может быть скрыт
  secondary: SecondaryAction[];
  tertiary?: TertiaryAction;
  layout: '2x50%' | '3x33%';
}
```

---

### Изменение 2: getScenarioConfig() возвращает null

**Файл:** `frontend/src/pages/HomePage.tsx` (~строка 387-390)

**Было:**
```typescript
// Сценарий 3: Нет активного голосования
return {
  hero: {
    title: 'Голосования',
    description: 'Создавайте и участвуйте в голосованиях',
    icon: <Vote />,
    buttonText: 'Создать голосование',  // ← Дублирование!
    buttonVariant: 'peach',
    showShimmer: true,
    onClick: handleGoToVoting,
  },
  secondary: [ ... ]
};
```

**Стало:**
```typescript
// Сценарий 3: Нет активного голосования
// Hero Action НЕ показывается - кнопка создания уже есть в пустом состоянии
return {
  hero: null,  // ← Скрываем Hero Action!
  secondary: [ ... ]
};
```

---

### Изменение 3: Условный рендеринг Hero Action

**Файл:** `frontend/src/pages/HomePage.tsx` (~строка 589-698)

**Было:**
```typescript
{/* Hero Action */}
<motion.div>
  <GlassCard>
    {/* ... */}
  </GlassCard>
</motion.div>
```

**Стало:**
```typescript
{/* Hero Action - показывается только при активном голосовании */}
{quickActionsConfig.hero && (  // ← Проверка на null!
  <motion.div>
    <GlassCard>
      {/* ... */}
    </GlassCard>
  </motion.div>
)}
```

## ✅ Преимущества

### 1. Нет дублирования ✅
- Только одна кнопка "Создать голосование"
- Чистый интерфейс

### 2. Контекстуальность ✅
- Кнопка создания в пустом состоянии (логично!)
- Hero Action при активном голосовании (уместно!)

### 3. Адаптивность ✅
- Hero Action показывается только когда нужна
- Интерфейс подстраивается под ситуацию

### 4. Чистота дизайна ✅
- Меньше элементов на экране
- Проще навигация
- Фокус на важном

1. Откройте главную страницу

3. **Проверьте:**

2. Откройте главную страницу
3. **Проверьте:**
   - ✅ InlineVotingCard показывается
   - ✅ Пустое состояние СКРЫТО
   - ✅ **Hero Action ПОКАЗЫВАЕТСЯ** ("Проголосовать")
   - ✅ Secondary Actions адаптированы (2 кнопки)
