## Общее Описание Проекта

### Концепция

**Rocket Lunch Bot** — это Telegram-бот с встроенным Mini App для организации коллективных заказов еды в рабочих группах. Система позволяет:

- Проводить голосования за блюда из меню
- Автоматически выбирать ответственного за заказ (рулетка)
- Управлять меню ресторанов
- Отслеживать статистику и историю заказов
- Вести учет бюджета и задолженностей

### Архитектура Взаимодействия

**Два режима работы:**

1. **Групповой режим** (в Telegram группах):
   - Бот публикует сообщения о голосованиях
   - Минимальный спам: максимум 3 сообщения на голосование
   - Deep Link для перехода в личный чат

2. **Личный режим** (Mini App в личном чате):
   - Полноценное веб-приложение внутри Telegram
   - Интерактивный интерфейс с анимациями
   - Управление меню, профилем, статистикой

### Основной Flow

```
Группа → Deep Link → Личный чат с ботом → Mini App → Голосование
```

## Telegram Bot - Взаимодействие в Группах

### Добавление Бота в Группу

**Шаг 1: Инициализация**

Когда администратор добавляет бота в группу:

1. Бот отправляет приветственное сообщение:
   ```
   👋 С возвращением, [Имя]!
   
   [Кнопка: 🍽️ Меню] [Кнопка: 📖 Команды]
   [Кнопка: 👥 О боте] [Кнопка: 👑 Админы]
   ```

2. Через 1 секунду отправляет инструкцию:
   ```
   👥 Групповой режим активирован!
   
   🔧 Для полного функционала:
   1. Сделайте меня администратором группы
   2. Используйте /startpoll для запуска голосования
   3. Участники смогут голосовать за блюда
   
   📱 Для управления меню:
   • Откройте бота @rocket_lunch_bot в личных сообщениях
   • Нажмите на кнопку Menu внизу экрана
   • Или используйте команду /menu в личке
   
   ⚡ Попробуйте /help для списка команд
   ```

**Расположение элементов:**
- Текст: центрировано по вертикали
- Кнопки: 2×2 сетка под текстом
- Каждая кнопка: во всю ширину своей ячейки

### Команда /startpoll - Создание Голосования

**Использование:**
```
/startpoll 30  (запуск голосования на 30 минут)
```

**Проверки при выполнении:**

1. **Проверка контекста:**
   - Команда работает ТОЛЬКО в группах
   - В личном чате: "Эта команда доступна только в группах"

2. **Проверка активного голосования:**
   - Если уже есть активное: "В этой группе уже есть активное голосование!"

3. **Проверка длительности:**
   - Валидный диапазон: 1-1440 минут (1 минута - 24 часа)
   - Значение по умолчанию: 30 минут
   - При ошибке: "Неверная длительность. Укажите число от 1 до 1440 минут."

4. **Проверка меню:**
   - Если меню пусто: "Меню пусто! Сначала добавьте блюда через Mini App."

**Сообщение после создания голосования:**

```
🗳️ Голосование за обед

⏰ Осталось: 30 мин
👥 Проголосовало: 0

Выберите блюдо в личке с ботом 👇

[Кнопка во всю ширину: 📱 Проголосовать]
```

**Расположение элементов:**
- Заголовок: жирный шрифт, сверху
- Emoji индикаторы: слева от текста
- Счетчики: обновляются каждую минуту автоматически
- Кнопка: во всю ширину внизу, яркая

**Поведение кнопки "Проголосовать":**

При нажатии открывается личный чат с ботом через Deep Link:
```
t.me/rocket_lunch_bot?start=vote_[POLL_ID]
```

### Завершение Голосования и Рулетка

**Автоматическое завершение:**

По истечении времени бот:

1. Убирает кнопку "Проголосовать" из сообщения
2. Отправляет уведомление:
   ```
   ⏰ Время голосования истекло!
   ```

3. Если были голоса, запускает рулетку:
   ```
   🎲 Рулетка завершена!
   
   🎯 Ответственный за заказ: @username
   🍽️ Блюдо-победитель: Пицца Маргарита
   
   📞 Иван, ожидаем вашего заказа! 😊
   ```

**Логика рулетки:**

- **Блюдо-победитель:** выбирается по максимальному количеству голосов
- **Ответственный:** выбирается случайно среди проголосовавших
- **Упоминание:** использует Telegram mention (кликабельное имя)

## Mini App - Главная Страница (HomePage)

### Общее Описание

**URL:** `https://yourdomain.com/` или `https://yourdomain.com/?pollId=123`

**Назначение:** Центральный хаб приложения, отображает текущее состояние и быстрые действия

**Дизайн:**
- Градиентный фон (меняется в зависимости от времени суток)
- Glassmorphism эффекты (полупрозрачные карточки)
- Плавные анимации при переходах
- Темная/светлая тема (автоматически из Telegram)

---

### Структура Страницы (Сверху Вниз)

#### 1. Верхняя Панель (Header)

**Расположение:** Самый верх экрана, фиксированная

**Элементы слева направо:**

- **Аватар пользователя** (слева)
  - Круглое фото профиля из Telegram
  - Размер: 40×40 пикселей
  - При отсутствии фото: инициалы на цветном фоне
  - При клике: переход на страницу профиля

- **Приветствие** (центр)
  - Формат: "[Emoji времени суток] [Приветствие], [Имя]!"
  - Примеры:
    - "🌅 Доброе утро, Иван!" (6:00-12:00)
    - "☀️ Добрый день, Иван!" (12:00-18:00)
    - "🌆 Добрый вечер, Иван!" (18:00-22:00)
    - "🌙 Доброй ночи, Иван!" (22:00-6:00)
  - Шрифт: средний, полужирный

- **Переключатель темы** (справа)
  - Иконка солнца/луны
  - При клике: переключение светлая ↔ темная тема
  - Сохраняется в localStorage

## Итоговая Сводка

### Основные Страницы Mini App

1. **HomePage** - Центральный хаб с quick actions
2. **VotingPage** - Интерактивное голосование
3. **MenuPage** - CRUD управление меню
4. **ProfilePage** - Профиль и настройки
5. **PollResultsPage** - Результаты с рулеткой
6. **PollHistoryPage** - История голосований
7. **StatsPage** - Статистика группы/личная
8. **AdminDashboardPage** - Админ-панель

### Telegram Bot Команды

- `/start` - Регистрация и приветствие
- `/startpoll [минуты]` - Создать голосование (группы)
- `/vote [ID]` - Голосование без Mini App (fallback)
- `/menu` - Показать меню
- `/help` - Список команд
- `/results` - Результаты последнего голосования
- `/stats` - Статистика группы

### Deep Links

- `vote_123` - Переход на голосование
- `menu_-1001234567` - Меню группы
- `poll_-1001234567` - Создание голосования
- `add_-1001234567` - Добавление блюда

### Ключевые Фичи

✅ Минимальный спам в группах (макс 3 сообщения)  
✅ Полноценный UI в Mini App  
✅ Live-обновления через WebSocket
