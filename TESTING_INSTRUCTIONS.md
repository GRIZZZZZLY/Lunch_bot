## Техническая информация

### Архитектура изменений

**React Query с query keys:**
```typescript
// Каждый пользователь имеет свой cache entry
queryKey: ['user', 'payment', userId]

// Примеры:
User A: ['user', 'payment', 123]
User B: ['user', 'payment', 456]
```

**Преимущества:**
- Автоматическая изоляция данных
- Optimistic updates (мгновенный отклик UI)
- Автоматический rollback при ошибках
- Нет ручного управления loading/error states

## Troubleshooting

### Проблема: Данные всё ещё смешиваются

**Решение:**
1. Очистить localStorage в браузере/WebView:
   ```javascript
   localStorage.clear()
   ```
2. Перезагрузить Mini App (закрыть и открыть заново)
3. Проверить что userId разный для пользователей в консоли

### Проблема: Активное голосование не видно

**Решение:**
1. Проверить что голосование создано (админ должен видеть)
2. Проверить backend логи - нет ошибок при `/api/polls/active`
3. Очистить cache React Query (перезагрузить Mini App)

### Проблема: Множественные уведомления

**Решение:**
1. Убедиться что используется новый билд (проверить timestamp файлов в `dist/`)
2. Проверить что FAB удалён (не должно быть 2 кнопок)
3. Проверить что `retry: 1` в mutation (не должно быть повторных запросов)
