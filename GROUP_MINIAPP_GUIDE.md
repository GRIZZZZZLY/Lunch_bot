# 📱 Как открыть Mini App в группе Telegram

## ⚠️ Важное ограничение Telegram

**Telegram не поддерживает кнопки Mini App в группах!**

Это ограничение Telegram API, а не ошибка бота. Кнопки `web_app` работают только в личных чатах.

**Документация:** `TELEGRAM_WEBAPP_LIMITATION.md`

## ✅ Решение реализовано!

Теперь в вашем боте есть **inline-кнопки** для открытия Mini App, которые работают как в личных чатах, так и в группах!

---

## 🚀 Как открыть Mini App если бот в группе

⚠️ **Кнопки Mini App НЕ работают в группах** (ограничение Telegram).

### Способ 1: Через личку с ботом (рекомендуется)

1. **Нажмите на имя бота** в группе
2. Выберите **Send Message** или **Start**
3. В личном чате нажмите кнопку **Menu** внизу экрана
4. Или отправьте `/menu` в личке
5. Нажмите **🚀 Открыть Mini App**

### Способ 2: Напрямую открыть бота

1. Найдите бота: [@rocket_lunch_bot](https://t.me/rocket_lunch_bot)
2. Нажмите **Start**
3. Нажмите кнопку **Menu** или **🚀 Открыть Mini App**

---

### Способ 2: Команда `/menu`
Показывает меню управления + кнопку Mini App:

```
/menu
```

---

### Способ 3: Команда `/start`
Приветственное сообщение + кнопка Mini App:

```
/start
```

## 📋 Настройка бота для работы в группах

### Шаг 1: Настройки в BotFather

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/mybots`
3. Выберите **@rocket_lunch_bot**
4. Bot Settings

#### Включите нужные настройки:

**Inline Mode:**
```
Bot Settings → Inline Mode → Turn ON
```

**Group Privacy** (важно!):
```
Bot Settings → Group Privacy → Turn OFF
```
⚠️ Это позволит боту видеть команды в группе.

**Allow in Groups:**
```
Bot Settings → Allow Groups? → YES
```

#### Обновите список команд:

```
Bot Settings → Edit Commands
```

Вставьте:
```
start - Начать работу с ботом
help - Показать справку
menu - Управление меню
app - Открыть Mini App
startpoll - Запустить голосование (админы)
history - История голосований
```

#### Настройте Menu Button (для личных чатов):

```
Bot Settings → Menu Button → Edit Menu Button URL
```

URL:
```
https://2072f129141b.ngrok-free.app
```

---

### Шаг 2: Добавьте бота в группу

1. Откройте вашу группу в Telegram
2. Нажмите на название группы → **Add Members**
3. Найдите **@rocket_lunch_bot**
4. Нажмите **Add**

---

### Шаг 3: Дайте боту права администратора

Это обязательно для работы голосований!

1. В группе: название → **Administrators**
2. **Add Administrator** → выберите @rocket_lunch_bot
3. Включите права:
   - ✅ **Send Messages**
   - ✅ **Delete Messages** 
   - ✅ **Pin Messages** (опционально)
4. Нажмите ✓ (галочка)

---

### Шаг 4: Протестируйте

В группе отправьте:
```
/app
```

Должна появиться кнопка **🚀 Открыть Mini App**. Нажмите на неё — откроется интерфейс приложения!

## ❓ Частые вопросы

### Q: Почему кнопка Menu не отображается в группе?

**A:** Menu Button (встроенная кнопка Telegram) работает **только в личных чатах**. 

В группах используйте команды:
- `/app` - для быстрого открытия Mini App
- `/menu` - для управления меню с кнопкой Mini App
- `/start` - для приветствия с кнопкой Mini App

---

### Q: Бот не отвечает на команды в группе

**Причины:**

1. **Privacy Mode включен** ❌
   - Решение: BotFather → Group Privacy → **DISABLED**

2. **Бот не имеет прав администратора** ❌
   - Решение: Сделайте бота админом группы

3. **Команда написана неправильно** ❌
   - Правильно: `/menu`
   - Неправильно: `menu` (без слеша)

---

### Q: Mini App не загружается

**Проверьте:**

1. **Backend запущен?**
   ```bash
   curl http://localhost:3001/health
   # Должен вернуть: {"status":"ok"...}
   ```

2. **ngrok туннель активен?**
   ```bash
   curl https://2072f129141b.ngrok-free.app/health
   # Должен вернуть тот же ответ
   ```

3. **URL в .env правильный?**
   ```env
   # backend/.env
   WEBAPP_URL=https://2072f129141b.ngrok-free.app
   CORS_ORIGIN=http://localhost:5173,https://2072f129141b.ngrok-free.app,https://web.telegram.org
   ```

4. **Перезапустите backend:**
   ```bash
   cd backend
   npm run dev
   ```

---

### Q: CORS ошибка при открытии Mini App

**Решение:**

Убедитесь, что в `backend/.env` правильно настроен CORS:

```env
CORS_ORIGIN=http://localhost:5173,https://2072f129141b.ngrok-free.app,https://web.telegram.org
```

И WEBAPP_URL:
```env
WEBAPP_URL=https://2072f129141b.ngrok-free.app
```

Перезапустите backend после изменений!

---

### Q: ngrok URL изменился, что делать?

**Быстрое решение:**

```powershell
# 1. Обновите конфигурацию
.\update-ngrok-url.ps1 -NewUrl "https://НОВЫЙ-URL.ngrok-free.app"

# 2. Переустановите webhook
.\set-webhook-now.ps1

# 3. Обновите Menu Button URL в BotFather
# @BotFather → @rocket_lunch_bot → Bot Settings → Menu Button
# Укажите: https://НОВЫЙ-URL.ngrok-free.app

# 4. Перезапустите backend
cd backend
npm run dev
```
