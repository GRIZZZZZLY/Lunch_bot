# 🔧 Исправление ошибки haptic.medium()

## ❌ Проблема

**Ошибка в консоли:**
```
Uncaught TypeError: haptic.medium is not a function
```

**Причина:**
Метод `haptic.medium()` **не существует** в хуке `useHaptic`.

---

## 🔍 Что было не так

### useHaptic возвращает только эти методы:
```typescript
{
  success(),   // ✅ Уведомление об успехе
  error(),     // ✅ Уведомление об ошибке
  warning(),   // ✅ Предупреждение
  impact(),    // ✅ Сильный отклик
}
```

### НЕТ метода:
```typescript
medium()  // ❌ НЕ СУЩЕСТВУЕТ!
```

---

## ✅ Решение

**Убрали вызовы `haptic.medium()`** из двух мест:

### 1. Функция handleGoToVoting
**Файл:** `frontend/src/pages/HomePage.tsx` (~строка 273)

**Было:**
```typescript
const handleGoToVoting = () => {
  haptic.medium();  // ❌ Ошибка!
  navigate('/poll/create');
};
```

**Стало:**
```typescript
const handleGoToVoting = () => {
  // haptic.medium(); // Метода medium() не существует
  navigate('/poll/create');
};
```

---

### 2. Большая кнопка в пустом состоянии
**Файл:** `frontend/src/pages/HomePage.tsx` (~строка 555)

**Было:**
```typescript
onClick={() => {
  haptic.medium();  // ❌ Ошибка!
  navigate('/poll/create');
}}
```

**Стало:**
```typescript
onClick={() => {
  // haptic.medium(); // Убираем вибрацию - она ломает навигацию
  navigate('/poll/create');
}}
```

---

## 📝 Когда использовать haptic

### ✅ Правильное использование:

```typescript
// Успешное действие (голосование, создание)
haptic.success();

// Ошибка
haptic.error();

// Предупреждение
haptic.warning();

// Критичное действие (удаление, завершение)
haptic.impact();
```

### ❌ НЕ используйте haptic для:
- Обычной навигации
- Кликов по карточкам
- Hover эффектов
- Прокрутки

**Причина:** Избыточная вибрация раздражает пользователей.
