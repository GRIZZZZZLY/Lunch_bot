## 🐛 Известные проблемы

### TypeScript ошибки при компиляции
**Статус:** Не критично для dev режима  
**Решение:** Использовать `npm run dev` (tsx watch)

### Уведомления ответственному
**Статус:** Требует доработки  
**Решение:** Передать bot instance в NotificationService

### Frontend требует HTTPS
**Статус:** Ограничение Telegram WebApp  
**Решение:** Использовать ngrok/localtunnel для тестирования
